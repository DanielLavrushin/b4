Sets

A set ties a list of targets, such as domains, addresses or networks, to what b4 does with their traffic: a DPI bypass strategy, a route through another interface or a proxy, or a block. The Sets page lists the sets and opens the set editor.

Guides that start here: Unblocking a site, Adding sites to a set, Blocking ads and sites, Importing from zapret or byedpi and Sharing a set.

Toolbar​

ControlWhat it does
Enable All / Disable AllTurns every set on or off at once.
Search sets...Shows only the sets whose name, domains, GeoSite categories or ASNs contain the text.
SelectSelects several sets. Delete removes the selected sets after a confirmation, and Cancel leaves the selection.
ImportBuilds sets from a byedpi or zapret command line, see Importing from zapret or byedpi.
Create SetOpens the editor for a new set.

Set order​

The handle at the top left of a card drags the set to another position. When several sets could match the same traffic, b4 picks the most specific match, not the first set in the list, and prefers a set limited to source devices. The order decides only between matches that are equally specific. Routing is the exception: the length of the range plays no part there. Sets limited to selected devices or source interfaces come first, and among sets of the same kind the one higher in the list wins.

How sets match traffic describes the full order of checks.

Set card​

A click on a card opens the set in the editor.

PartShows
Switch and numberThe switch turns the set on or off. The number is the set's position in the list.
Name and targetsThe set's name and a summary of its targets.
Route lineWhat the set does with the traffic it matches: Default route for a set that only applies a bypass strategy, the interface or socks5 proxy it routes through, Telegram bridge, or block with the block action.
Facet railThe marks along the top of the card: Target, Split, Fake, Route, DNS and Escalate. A mark opens a summary of that part of the set, with a link to its tab in the editor. Compare across sets above the list opens the same part on every card at once.
Badgesescalates to names the backup set, and fallback for names the sets that use this one as their backup. N ASN unresolved means an ASN has no prefixes yet. Watchdog appears while Keep this set working with the watchdog is on for the set, and opens the watchdog page. Imported shared set and Community set mark a set that came from someone else.

The menu at the top right of a card holds:

ItemWhat it does
EditOpens the set in the editor.
DuplicateCreates a copy of the set.
CompareOpens Compare Sets with this set and another side by side. Differences only hides the fields that match.
Find a strategyOpens Discovery for the set. Not shown for a set that routes its traffic.
DeleteDeletes the set after a confirmation.

Set editor​

The top bar holds the set's name. Save Changes, or Create Set for a new set, saves it, and so does the round button at the bottom right. Back and Cancel return to the list without saving.

TabWhat it holds
TargetsWhich traffic the set applies to: domains, GeoSite categories, addresses, GeoIP categories, ASNs and source devices.
TCPThe DPI bypass strategy for TCP, on the General, Splitting and Faking sub-tabs.
UDPWhich QUIC and other UDP traffic the set matches, and what b4 does with it.
DNS & RoutingThe DNS redirect, routing through an interface or a proxy, blocking, and the set's DSCP value.
EscalationA backup set for the sites this set keeps failing on.
DiscoveryThe addresses Discovery tests for the set, the last search for it, and the watchdog switch.
Import/ExportThe set as JSON, and a shared set for other people.

Import/Export​

The tab shows the set as JSON under Set Configuration JSON. Copy JSON copies it. A JSON pasted into the field and loaded with Import replaces the content of the editor, and it takes effect after Save Changes.

The JSON is for moving a set between one's own routers. It leaves out what only makes sense on this router:

  • the source devices, and with them the set's own DSCP value;
  • the Escalation settings, which point to other sets;
  • the watchdog switch. The Discovery addresses are carried, and the watchdog switch of the set the JSON is imported into stays as it was.

These are set again on the other router. A set can use a payload file that this router does not have. A warning after the import then names the file, and the fake packets use a built-in payload until it is uploaded under Settings > Payloads.

A set for someone else is a shared set, which leaves out everything tied to this router. With the Community Hub switched on under Settings > Integrations, the same tab prepares one. The Import field accepts both forms.
