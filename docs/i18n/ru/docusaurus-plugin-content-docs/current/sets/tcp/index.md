Вкладка **TCP** содержит стратегию обхода DPI сета для TCP-соединений, например HTTPS. На ней три подвкладки:

| Подвкладка | Что на ней |
| --- | --- |
| [Основные](./general.md) | Задержка сегмента и фильтр портов, дублирование пакетов, обнаружение блокировки по IP, [защита от RST-инъекций](./rst-protection.md) и MSS clamping. |
| [Разделение](./splitting.md) | Как b4 разделяет первый пакет данных соединения - TLS ClientHello. |
| [Фейкинг](./faking.md) | Фейковые пакеты, которые DPI читает, а сервер отбрасывает, и изменения настоящего ClientHello. |

[Дискавери](../../discovery.md) проверяет стратегии на заблокированном сайте и записывает в сет рабочие значения. Стратегию, которую предлагает Дискавери, рекомендуется пробовать первой, а ручные изменения на этих подвкладках нужны для её доводки.

Сет может вести свой трафик через прокси или через поднятый туннельный интерфейс на вкладке [DNS & Маршрутизация](../routing.md). Тогда b4 не трогает его пакеты: разделение, фейкинг, дублирование пакетов и обнаружение блокировки по IP не применяются.
