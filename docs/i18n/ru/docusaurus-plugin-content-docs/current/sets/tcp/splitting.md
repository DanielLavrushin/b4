Подвкладка **Разделение** определяет, как b4 разделяет первый пакет данных соединения, TLS ClientHello, чтобы DPI не мог прочитать в нём имя сервера. [Дискавери](../../discovery.md) проверяет методы на заблокированном сайте, и метод, который она предлагает, рекомендуется пробовать первым. Ручные изменения нужны для доводки.

![Раздел «Стратегия разделения» с методом Combo](/img/splitting/20260323224335.png)

## Стратегия разделения

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Метод** | Метод разделения, см. таблицу ниже. Настройки выбранного метода появляются под ним. | **Combo** |
| **Обратный порядок фрагментов** | Отправляет второй фрагмент первым. | Вкл. |
| **Пул рандомизации стратегий** | Методы, из которых b4 случайно выбирает для каждого нового соединения, чтобы соединения отличались. Пустой пул - используется **Метод**. | Пусто |

| Метод | Что делает |
| --- | --- |
| **Combo** | Разделяет в нескольких точках, перемешивает сегменты и добавляет случайные задержки. Может добавить обманку и фейковые пакеты между сегментами. |
| **Hybrid** | Для каждого ClientHello выбирает Combo, Disorder, Extension Split или First-Byte Desync по тому, какие точки разделения в нём находит. Своих настроек нет. |
| **Disorder** | Отправляет настоящие сегменты не по порядку со случайными задержками, без фейковых пакетов, если не включён **Фейк на сегмент**. |
| **Extension Split** | Разделяет ClientHello прямо перед расширением SNI. Своих настроек нет, используются **Обратный порядок фрагментов** и **Задержка сегмента 2**. |
| **First-Byte Desync** | Отправляет один байт, ждёт, потом отправляет остальное, и DPI сдаётся раньше, чем приходит имя сервера. Ожидание - это **Задержка сегмента 2** на подвкладке [Основные](./general.md), не меньше 100 мс. |
| **TCP Segmentation** | Разделяет пакет на TCP-сегменты. |
| **IP Fragmentation** | Разделяет IP-пакет на IP-фрагменты. |
| **TLS Record Splitting** | Разделяет ClientHello на несколько TLS-записей внутри одного TCP-пакета. |
| **OOB (Out-of-Band)** | Вставляет байт с TCP-флагом URG. Сервер его игнорирует, а DPI, который следит за соединением, читает его как данные. |
| **Отключено** | Без разделения. Используются только фейковые пакеты, если они включены. |

## TCP Segmentation и IP Fragmentation

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Умное разделение SNI** | Разделяет в середине имени сервера. Рекомендуемый вариант. | Вкл. |
| **Фиксированная позиция разделения** | Разделяет на этом числе байт от начала TLS payload, от 0 до 50, `0` выключает. Если задан диапазон, каждое соединение выбирает случайную позицию. Если включено и **Умное разделение SNI**, пакет делится на три сегмента. | `1` |

## Combo

![Точки разделения Combo](/img/splitting/20260323224920.png)

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Первый байт** | Разделяет после первого байта. | Вкл. |
| **Разделение по расширению** | Разделяет перед расширением SNI. | Вкл. |
| **Разделение SNI** | Разделяет в середине имени сервера. | Вкл. |
| **Включить обманку** | Перед настоящим ClientHello отправляет фейковый с разрешённым именем сервера. У фейка низкий TTL, поэтому DPI его видит, а сервер нет. | Выкл. |
| **Режим перемешивания** | **Только средние** оставляет первый и последний сегменты на месте, **Полное перемешивание** переставляет все, **Обратный порядок** отправляет последний сегмент первым. | **Полное перемешивание** |
| **Задержка первого сегмента** | Пауза после первого сегмента, от 10 до 500 мс. | `30` |
| **Макс. джиттер** | Наибольшая случайная задержка между остальными сегментами, от 100 до 10 000 мкс. | `1000` |
| **Фейк на сегмент** | Отправляет фейковые перекрывающие пакеты перед каждым сегментом, а не только перед первым. **Фейков на сегмент** задаёт их число, от 1 до 11. | Выкл. |

Если все точки разделения выключены, Combo отправляет пакет одним куском, и вкладка показывает предупреждение.

## Disorder

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Разделение по SNI** | Разделяет вокруг имени сервера. | Вкл. |
| **Режим перемешивания** | **Полное перемешивание** или **Обратный порядок**. | **Полное перемешивание** |
| **Мин. джиттер**, **Макс. джиттер** | Случайная задержка между сегментами, в мкс. Действует, пока **Задержка сегмента 2** равна 0. **Макс. джиттер** должен быть больше, чем **Мин. джиттер**. | `1000`, `3000` |
| **Фейк на сегмент** | Как в Combo. | Выкл. |

## Перекрытие последовательности (seqovl) {#sequence-overlap}

Есть у Combo и Disorder. b4 ставит фейковые байты перед настоящим сегментом и сдвигает его sequence number назад на столько же. DPI читает фейковые байты как начало данных, а сервер их отбрасывает.

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Паттерн перекрытия** | Фейковые байты: **Нет**, **Заголовок TLS 1.2**, **Заголовок TLS 1.1**, **Заголовок TLS 1.0**, **HTTP GET**, **Нули** или **Пользовательский** набор hex-байтов. | **Нет** |
| **Длина перекрытия** | Сколько байт паттерна добавить. `0` выключает перекрытие. | `0` |

## OOB (Out-of-Band)

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Позиция вставки** | Сколько байт идёт перед вставленным байтом, от 1 до 50. Если задан диапазон, каждое соединение выбирает случайную позицию. | - |
| **OOB байт** | Байт, который отправляется вне основного потока. | `x` |

## TLS Record Splitting

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Позиция разделения записи** | Размер первой TLS-записи в байтах, от 1 до 100. Если задан диапазон, каждое соединение выбирает случайный размер. | - |
