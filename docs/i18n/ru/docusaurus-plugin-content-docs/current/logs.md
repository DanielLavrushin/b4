Страница **Логи** показывает лог b4 по мере записи.

## Управление

| Элемент | Что делает |
| --- | --- |
| **Фильтр логов...** | Оставляет только строки, которые содержат текст, без учёта регистра. |
| **ERROR**, **WARN**, **INFO**, **TRACE**, **DEBUG** | Показывают или скрывают строки каждого уровня. На каждом значке - число строк. |
| **Поток** / **Пауза** | Приостанавливает и возобновляет поток. |
| **Очистить логи** | Удаляет строки, показанные в браузере. Лог на роутере не меняется. |

**P** или **Pause** приостанавливает и возобновляет поток, **Ctrl+X** или **Delete** очищает его.

## Запись трассировки

Трассировка сохраняет лог одного сеанса в файл для отчёта об ошибке.

1. Нажмите **Начать трассировку**.
2. Воспроизведите проблему.
3. Нажмите **Остановить и сохранить**. Браузер скачает файл трассировки.

**Скачать последнюю трассировку** скачивает последнюю трассировку ещё раз. Файл начинается с версии b4, снимка системной диагностики и включённых сетов, за ними идут строки лога, записанные за сеанс. Трассировка останавливается сама через 15 минут. Хранится только последняя трассировка.

Что ещё нужно для отчёта об ошибке, перечислено в разделе [Сообщение о проблеме](./troubleshooting/reporting.md).

## Уровень логирования

Подробность лога задаёт поле **Уровень логирования** в карточке **Логирование** раздела **Настройки > Система > Сервис**, см. [Логирование](./settings/system.md#logging).
