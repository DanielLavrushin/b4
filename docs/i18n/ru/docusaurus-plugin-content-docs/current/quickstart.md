## Обзор

После установки b4 запускается как сервис и становится доступен через веб-интерфейс. Эта страница описывает путь от первого запуска до работающего обхода блокировок.

## Открыть веб-интерфейс

Откройте в браузере:

```text
http://<IP-адрес>:7000
```

Где `<IP-адрес>` - адрес устройства, на котором установлен b4:

- Если b4 на этом же компьютере: `http://localhost:7000`
- Если на роутере: `http://192.168.1.1:7000` (подставьте IP роутера)

:::info HTTPS
Если в настройках b4 включён HTTPS, используйте `https://` вместо `http://`. Браузер может показать предупреждение о сертификате - это нормально для самоподписанного сертификата, его можно принять.
:::

![dashboard](/img/quickstart/20260323203514.png)

При первом запуске дашборд будет пустым - это нормально. Данные появятся после настройки.

## Запустить Дискавери

b4 может сам подобрать рабочую конфигурацию для вашего провайдера. Для этого используется раздел **Дискавери**.

### Шаг 1: Перейти в Дискавери

В боковом меню нажмите **Дискавери**.

### Шаг 2: Добавить сайты

В поле **Сайт или URL** введите адрес заблокированного сайта и нажмите Enter. Несколько сайтов добавляются сразу, через запятую.

Примеры:

- `youtube.com`
- `googlevideo.com`

![Сайты добавлены в Дискавери](/img/quickstart/ru/20260905160500.png)

### Шаг 3: Начать поиск

Нажмите **Начать**.

b4 перебирает стратегии обхода на указанных сайтах. Запуск проходит шесть шагов, которые видны на странице: проверка DNS, запрос без обхода, сами стратегии, подбор параметров, комбинации и подтверждение победителя.

![Запуск в процессе](/img/quickstart/ru/20260905160600.png)

Запуск занимает от одной до десяти минут в зависимости от провайдера. **Остановить и сохранить найденное** завершает его раньше и сохраняет всё, что найдено.

:::tip Проверка DNS
Если известно, что DNS не подменяется, например уже используется DoH или сторонний резолвер, параметр **Проверять подмену DNS** в **Параметрах** можно выключить. Запуск станет короче, а в сет не попадёт DNS-перенаправление.
:::

### Шаг 4: Результаты

После завершения каждый сайт получает вердикт:

- **Стратегия найдена** - рабочая конфигурация, описанная словами, с кнопкой **Применить как сет**
- **Обход не нужен** - сайт открывается без b4, применять нечего
- **Адрес заблокирован** - соединения с адресами сайта обрываются, стратегия обхода не поможет, нужен сет с прокси или VPN
- **Ничего не найдено** - ни одна стратегия не открыла сайт

![Результаты запуска](/img/quickstart/ru/20260905160700.png)

## Применить конфигурацию

На карточке найденной стратегии нажмите **Применить как сет**.

В открывшемся диалоге:

1. Проверьте строки с описанием того, что сделает сет
2. Оставьте предложенное название или введите своё
3. Нажмите **Создать сет** либо выберите существующий сет с той же стратегией и нажмите **Добавить в сет**

Сет - это набор настроек обхода, привязанный к списку доменов или ip адресов. Подробнее о сетах - в разделе [Сеты](./sets/).

## Проверить работу

### Через браузер

Откройте сайт, для которого настроен обход. Если всё работает - сайт загрузится.

### Через раздел Соединения

В боковом меню нажмите **Соединения**. Здесь отображаются все текущие TCP/UDP-соединения в реальном времени.

![connections](/img/quickstart/20260323204510.png)

Если обход работает, в столбце **Сет** напротив соединений с настроенным доменом будет отображаться название вашего сета.

## Что дальше

- Добавить другие домены - через Дискавери или вручную в настройках сета

- Настроить обход по категориям (GeoSite) - чтобы не добавлять домены по одному
- Посмотреть раздел [Сеты](./sets/) для подробного описания всех возможностей
