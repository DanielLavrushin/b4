## Требования

- Роутер Keenetic с поддержкой OPKG.
- Entware.
- Компоненты Netfilter, см. [ниже](#netfilter-components).

## Установка Entware

### Новые модели, со встроенным хранилищем

1. Откройте веб-интерфейс роутера.
2. Откройте **Управление > Настройки системы**.
3. Включите компонент **Менеджер пакетов OPKG**.

### Старые модели, с USB-накопителем

1. Подключите USB-накопитель к роутеру.
2. Установите Entware через менеджер пакетов.

Подробности - в [справке Keenetic](https://help.keenetic.com/hc/en-us/articles/360021214160).

## Компоненты Netfilter {#netfilter-components}

В KeeneticOS нет всех модулей netfilter, которые нужны b4, поэтому до установки b4 включаются два компонента. Компоненты системы доступны только под учётной записью `admin`.

1. В веб-интерфейсе роутера откройте **Управление > Настройки системы** и нажмите **Изменить набор компонентов**.
2. Найдите компоненты по слову `netfilter` и отметьте **Модули ядра подсистемы Netfilter**, если они ещё не отмечены.
3. Отметьте **Пакет расширения Xtables-addons для Netfilter**. Он появляется в списке, когда отмечены модули Netfilter.
4. Примените изменения, затем перезагрузите роутер или примените компоненты.
5. По SSH установите пользовательскую часть iptables:

   ```bash
   opkg install iptables
   ```

## Установка b4

По SSH на роутере:

```bash
curl -fsSL https://raw.githubusercontent.com/DanielLavrushin/b4/main/install.sh | sh
```

Установщик сам определяет архитектуру: `mipsle_softfloat` на старых моделях (MT7621), `arm64` на новых (aarch64).

:::warning Без Entware
Без Entware b4 устанавливается в `/tmp`, который очищается при каждой перезагрузке. С Entware b4 сохраняется после перезагрузки.
:::

## Управление сервисом

```bash
/opt/etc/init.d/S99b4 start
/opt/etc/init.d/S99b4 stop
/opt/etc/init.d/S99b4 restart
```

## Пути

| Что | Где |
| --- | --- |
| Бинарник | `/opt/sbin/b4` |
| Конфигурация | `/opt/etc/b4/b4.json` |
| Сервис | `/opt/etc/init.d/S99b4` |

## Перезапись firewall {#firewall-rewrites}

KeeneticOS время от времени перестраивает свой файрвол и удаляет при этом правила b4. Установщик добавляет хук, по которому b4 восстанавливает их сразу после перестройки. Какие строки это оставляет в логе, описано на странице [Особенности платформ](../troubleshooting/platforms.md#keenetic-firewall-rewrites).

## DNS-запросы {#dns-queries}

На KeeneticOS с ядром до 4.18 (4.14 до 4.14.173) b4 копирует DNS-запросы, а не задерживает их. Что от этого меняется, описано на странице [Особенности платформ](../troubleshooting/platforms.md#keenetic-dns-queries).

## Решение проблем

После запуска сервиса лог ошибок показывает, не было ли сбоев:

```bash
cat /var/log/b4/errors.log
```

Ошибки и способы их исправить перечислены на странице [Особенности платформ](../troubleshooting/platforms.md#keenetic). Если ошибок нет, веб-интерфейс доступен по LAN-адресу роутера на порту 7000.
