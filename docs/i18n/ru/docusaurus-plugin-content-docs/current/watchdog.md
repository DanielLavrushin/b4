Страница **Мониторинг** показывает сеты и домены, которые проверяет мониторинг, их статус и последние восстановления. Мониторинг по расписанию запрашивает страницы сета. Если они продолжают не открываться, он восстанавливает сет: запускает для него [Дискавери](./discovery.md), записывает найденную стратегию и отменяет изменение, если страницы по-прежнему не открываются. Настройка описана в руководстве [Поддержание работы сетов](./guides/keep-working.md).

По умолчанию мониторинг выключен. **Включить мониторинг** в разделе [Настройки > Дискавери](./settings/discovery.md#мониторинг) включает его для всех сетов и доменов.

## Мониторинг сета

Сет отслеживается, пока на его [вкладке Дискавери](./sets/discovery.md#мониторинг) включён переключатель **Поддерживать работу сета с помощью мониторинга**. Кроме того, сет должен быть включён, иметь адреса Дискавери, не маршрутизировать трафик, не быть ограничен отдельными устройствами через список включения и иметь цели-домены или категории GeoSite. Вкладка называет невыполненное условие.

## Проверки

Проверка запрашивает адреса Дискавери сета через b4 так же, как к ним обращается устройство за роутером. Сет проверяется сразу, как только становится отслеживаемым, затем через каждый **Интервал проверки**, а после неудачной проверки - через **Интервал после ошибки**.

Адрес, который обрабатывает другой сет или который [эскалация](./sets/escalation.md) сейчас отправляет в другой сет, не учитывается: стратегия, записанная в этот сет, на него не действует. Адрес не проходит проверку, если он не открывается, отвечает ошибкой HTTP вроде 451 или 5xx, отдаёт страницу блокировки или обрывается. Ошибка сертификата, требование клиентского сертификата или частный адрес дают адресу статус **Непригоден**: стратегия этого не изменит, поэтому такой адрес не восстанавливается.

## Восстановление

После **Макс. попыток** неудачных проверок подряд мониторинг запускает [Дискавери для сета](./discovery.md#запуск-для-сета). Восстановления идут по одному, а ручной запуск Дискавери заставляет их ждать. Восстановление видно на странице Дискавери, но остановить его там нельзя.

Восстановление записывает только стратегию, которая работает на всех адресах, и только стратегию обхода, как описано в разделе [Запись в существующий сет](./discovery.md#запись-в-существующий-сет). Затем адреса проверяются снова, и если какой-то по-прежнему не открывается, возвращается прежняя стратегия сета. Другие сеты восстановление не затрагивает.

После каждого восстановления сет ждёт **Перерыв между discovery**. После трёх неудачных восстановлений подряд мониторинг прекращает поиск для сета. Проверки продолжаются, но восстановление не начинается, пока не произойдёт одно из:

- проверка показала, что все адреса открываются;
- нажата кнопка **Проверить сейчас**;
- мониторинг сета выключен и снова включён.

Страница, открытая до восстановления, например редактор сета, не может его отменить. Её сохранение отклоняется с предложением перезагрузить данные, а несохранённые изменения при этом теряются.

## Статусы

Статус отслеживаемого сета виден здесь, на его вкладке Дискавери, на его карточке на странице **Сеты** и на дашборде.

| Статус | Значение |
| --- | --- |
| **В очереди** | Ещё не проверялся или ждёт новой проверки после изменения. |
| **Работает** | Открылись все адреса, которые удалось проверить. |
| **Проблема** | Хотя бы один адрес не открылся. В строке видно число неудачных проверок подряд. |
| **Поиск в очереди** | Достигнуто значение **Макс. попыток**, и восстановление ждёт своей очереди. |
| **Идёт поиск** | Идёт запуск Дискавери для восстановления. |
| **Пауза** | Восстановление не удалось или ничего не записало, и следующая проверка ждёт окончания паузы. |
| **Нельзя проверить** | Ни один адрес нельзя проверить: каждый обрабатывает другой сет, уходит в эскалацию или непригоден. |
| **Поиск прекращён** | Три восстановления подряд не удались. Проверки продолжаются, восстановления - нет. |

Каждый адрес показывает **Работает**, **Ошибка**, **Другой сет** (с названием сета, который его обрабатывает), **Эскалация**, **Непригоден** или **В очереди**.

Причина под статусом сета объясняет, почему он в этом состоянии или чем закончилось последнее восстановление:

| Причина | Значение |
| --- | --- |
| Другой сет | Адреса обрабатывает другой сет или никакой, поэтому стратегия, записанная в этот сет, на них не действует. |
| Текущая стратегия работает | При отдельной проверке стратегия сета открывает адреса, но живая проверка не проходит. Мешает что-то помимо стратегии: другой сет, DNS или IPv6. Ничего не изменено. |
| Обход не нужен | При отдельной проверке адреса открываются без обхода, но живая проверка не проходит. Причины те же. |
| Частичный результат | Стратегия нашлась только для части адресов. Ничего не записано. |
| Ничего не найдено | Поиск не нашёл рабочей стратегии. |
| Дольше 20 минут | Поиск шёл слишком долго и был остановлен. Следующая попытка - после паузы. |
| Проверка не пройдена | Стратегия не прошла живую проверку и была отменена. |
| Сет изменён | Сет изменился во время поиска, поэтому ничего не записано. |
| Занято | Шёл другой запуск Дискавери. Мониторинг повторит попытку позже. |

## Отслеживаемые сеты

Каждая строка раздела **Отслеживаемые сеты** открывает вкладку Дискавери сета. В ней видны статус и причина, время последней проверки, **Последнее восстановление** с записанной стратегией, **Неудачные восстановления** и окончание паузы в поле **Пауза**. **Показать адреса** выводит каждый адрес со статусом, HTTP-ответом и последней ошибкой.

**Проверить сейчас** сразу проверяет все адреса и сбрасывает паузу, счётчик неудачных восстановлений и прекращение поиска. Пока восстановление в очереди или идёт, кнопка недоступна. **Перестать отслеживать сет** выключает мониторинг сета.

## Параметры

Карточка **Мониторинг** в разделе [Настройки > Дискавери](./settings/discovery.md#мониторинг) задаёт интервалы сразу для сетов и доменов: **Интервал проверки**, **Интервал после ошибки**, **Перерыв между discovery**, **Таймаут проверки** и **Макс. попыток**.

## Старый список доменов

**Старый список доменов** содержит домены, которые проверяются по одному. Он появился раньше мониторинга сетов и продолжает работать рядом с ним. Домен добавляется в поле над списком или в разделе **Настройки > Дискавери**. Запись - домен, который проверяется как `https://<домен>/`, или полный URL.

После **Макс. попыток** неудачных проверок для домена запускается Дискавери. Подтверждённая стратегия записывается в первый включённый сет без маршрутизации, в списке доменов которого есть этот домен или его родительский домен. Если такого сета нет, создаётся новый сет `watchdog-<домен>`. В сет, который маршрутизирует или блокирует трафик, домен не записывается никогда.

| Статус | Значение |
| --- | --- |
| **Доступен** | При последней проверке домен открылся. |
| **Проблема** | Ошибки зафиксированы, но **Макс. попыток** ещё не достигнуто. |
| **Восстановление** | Для домена идёт запуск Дискавери. |
| **В очереди** | Домен ждёт следующей проверки. |

Запись, хост которой уже проверяет отслеживаемый сет, показана как **Проверяется через сет &lt;имя&gt;**. **Отслеживать через &lt;сет&gt;** переносит запись в сет, который обрабатывает её хост. Кнопка добавляет адрес в адреса Дискавери этого сета, включает для него мониторинг и убирает запись из списка. Рекомендуется отслеживать сам сет: его восстановление всегда записывает в этот сет и проверяет все его страницы вместе.
