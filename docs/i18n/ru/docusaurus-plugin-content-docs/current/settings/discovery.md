# Настройки дискавери

Параметры автоматического поиска конфигурации. Настраиваются в **Настройки → Дискавери**.

![Настройки Дискавери](/img/discovery/ru/20261003230000.png)

## Параметры

| Параметр | Описание | Диапазон | По умолчанию |
| --- | --- | --- | --- |
| Таймаут поиска | Максимальное время ожидания ответа при проверке каждой стратегии | 3–30 сек | `5` сек |
| Задержка распространения | Время ожидания после применения конфигурации перед тестированием. Нужно, чтобы правила успели активироваться | 500–5000 мс | `1500` мс |

Сколько запросов подряд должен пройти пресет, задаётся для каждого запуска параметром **Подтверждать каждую стратегию** на странице [Дискавери](../discovery#параметры).

## Доверенный DNS-сервер

При включённом **Проверять подмену DNS** Дискавери сравнивает адрес каждого сайта от резолвера роутера с адресом от резолвера, которому доверяет, и так определяет, выдаёт ли DNS неверный адрес. **Доверенный DNS-сервер** задаёт этот резолвер. Если поле пустое, Дискавери опрашивает публичные резолверы, встроенные в b4: сначала DNS поверх HTTPS, затем обычный DNS.

| Форма | Транспорт |
| --- | --- |
| `9.9.9.9`, `2620:fe::fe`, `127.0.0.1:53053`, `udp://9.9.9.9` | Обычный DNS по UDP, с повтором по TCP, если ответ обрезан |
| `tcp://9.9.9.9` | Обычный DNS только по TCP |
| `tcp+udp://127.0.0.1:53053` | Сначала UDP, по TCP - если UDP не сработал |
| `https://dns.google/dns-query` | DNS поверх HTTPS; если в URL нет пути, добавляется `/dns-query` |

По умолчанию используется порт 53. Обычному DNS нужен IP-адрес: имя хоста работает только в URL `https://`. DNS поверх TLS и другие транспорты напрямую не поддерживаются; их покрывает локальный DNS-прокси, который их умеет, если указать здесь его адрес.

Указанный здесь сервер - единственный эталон. Его ответы считаются верными адресами сайтов, его NXDOMAIN - признаком несуществующего имени, а публичные резолверы рядом с ним не опрашиваются. Перед началом запуска сервер один раз опрашивается об одном из имён, которые проверяет запуск; если ответ не приходит или сервер отказывает в запросе, запуск останавливается с ошибкой. Ответ с ошибкой об этом имени, например SERVFAIL, запуск не останавливает, а запуск, все имена которого закреплены, сервер не опрашивает. Если сервер перестаёт отвечать позже, сайт, о котором его спрашивали, остаётся без сравнения DNS.

Если резолвер роутера выдаёт сайту неверный адрес, предложенный сет получает исправление DNS - первое сработавшее из:

1. самого доверенного сервера, если сет может им пользоваться: публичный IP-адрес на порту 53, ответивший по UDP, или URL `https://`;
2. встроенного сервера DNS поверх HTTPS, который возвращает верный адрес сайта;
3. встроенного обычного DNS-сервера, который возвращает его же, при обычном запросе, а затем при фрагментированном;
4. [закрепления](../dns#закреплённые-адреса) в сете адресов, полученных от DNS поверх HTTPS или доверенного сервера, если ни один резолвер, доступный сету, их не возвращает; ответ встроенных обычных DNS-серверов не закрепляется никогда, потому что его можно подделать по пути.

Доверенный сервер, которым сет пользоваться не может, например локальный прокси на другом порту, резолвер в локальной сети или сервер `tcp://`, всё равно определяет, какие адреса верные, а журнал запуска объясняет, почему он не попал в сет. Резолвер в локальной сети не подходит потому, что DNS-перенаправление сета перехватывает и запросы, которые этот резолвер отправляет дальше через роутер, и вернуло бы их ему же.

То же поле есть в [параметрах запуска Дискавери](../discovery#параметры), где оно действует только на этот запуск.

:::warning Скорость в результатах дискавери
Скорость, которую показывает дискавери (например, «40 КБ/с»), - это **не реальная скорость** вашего соединения. При тестировании загружается очень маленький объём данных, недостаточный для точного измерения. Эти цифры нужны только для **сравнения стратегий между собой** - какая быстрее, какая медленнее. Не ориентируйтесь на абсолютные значения.
:::

## Мониторинг

Блок «Мониторинг» содержит общий переключатель **Включить мониторинг**. Пока он включён, в блоке показываются также четыре интервала, **Макс. попыток** и **Старый список доменов**. Переключатель включает и выключает весь мониторинг, и для отслеживаемых сетов, и для старого списка, а интервалы действуют для обоих. Каждый параметр с диапазоном и значением по умолчанию описан в разделе [Параметры мониторинга](../watchdog#параметры).

**Старый список доменов** содержит домены, которые проверяются по одному, и каждый восстанавливается через тот сет, в котором он указан в этот момент; см. [Старый список доменов](../watchdog#старый-список-доменов). Тот же список можно редактировать на странице мониторинга.

:::info Мониторинг сета
Сет ставится на мониторинг на его собственной [вкладке Дискавери](../sets/discovery#мониторинг) переключателем **Поддерживать работу сета с помощью мониторинга**. Тогда его адреса Дискавери проверяются вместе, а восстановление записывает только в этот сет. Чтобы проверялся хоть один сет, переключатель здесь всё равно должен быть включён.
:::
