Вкладка **Интеграции** подключает b4 к внешним сервисам. **AI-помощник** позволяет b4 спрашивать AI-провайдера о своих настройках, а **MCP-сервер** позволяет AI-приложению спрашивать b4. Изменения сохраняются кнопкой **Сохранить** в заголовке страницы.

## IPinfo {#ipinfo}

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Токен доступа** | Токен ipinfo.io. С ним окно **Добавить в сет** на странице [Трафик](../connections.md#добавление-адресов-и-сетей-в-сеты) и на дашборде предлагает кнопку **Обогатить через IPInfo**: она показывает организацию, имя хоста и расположение адреса. Эти сведения b4 запрашивает с роутера. **Получить токен** открывает ipinfo.io, бесплатного тарифа достаточно. | Пусто |

## AI-помощник {#ai-assistant}

Помощник объясняет настройки прямо в веб-интерфейсе. Вопрос b4 отправляет выбранному AI-провайдеру. Пока помощник включён, рядом со многими полями, в основном в редакторе сета, виден значок AI, а **Спросить AI об этой настройке** открывает ответ.

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Включить AI-помощника** | Переключатель в заголовке карточки. | Выкл |
| **OpenAI**, **Anthropic**, **Ollama**, **OpenAI-compatible** | Провайдер. С OpenAI и Anthropic вопросы и затронутые ими части конфигурации уходят с роутера к этому провайдеру. С Ollama они остаются локально. | Не выбран |
| **Модель** | Модель из списка провайдера или введённая вручную. | Пусто |
| **API-ключ** | Обязателен для OpenAI и Anthropic, необязателен для OpenAI-compatible. **Задать ключ** сохраняет его на роутере в отдельном файле, а не в конфигурации. | Пусто |

Раздел **Дополнительно** содержит параметры подключения.

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Endpoint** | Адрес API провайдера, подставляется для каждого провайдера. Другое значение указывает на другой сервер, например собственный. | Свой у каждого провайдера |
| **Макс. токенов** | Наибольшая длина ответа в токенах. | `1024` |
| **Температура** | От 0 до 2. Чем меньше значение, тем предсказуемее ответы. | `0.2` |
| **Таймаут (с)** | Сколько может длиться один запрос. | `120` |

Пока провайдером пользоваться нельзя, например без ключа, карточка показывает причину.

## MCP-сервер {#mcp-server}

MCP-сервер позволяет AI-приложению, например Claude Desktop, Cursor или LM Studio, читать состояние b4, а с разрешения - менять его настройки. Модель работает в самом приложении, поэтому b4 не нужен API-ключ. Настройка описана в руководстве [Подключение AI-помощника](./mcp.md).

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Включить MCP-сервер** | Переключатель в заголовке карточки. Сервер работает на порту веб-интерфейса. | Выкл |
| **Токен доступа** | Токен, который предъявляет AI-приложение. **Сгенерировать** создаёт его, **Пересоздать** заменяет. Без токена приложению нужен вход в веб-интерфейс, а он сбрасывается при перезапуске b4. | Пусто |
| **Разрешить изменение настроек** | Позволяет AI менять сеты и настройки MTProto, SOCKS5 и логирования, а не только читать их. Учётные данные и все остальные настройки остаются только для чтения. | Выкл |
| **Разрешить активные проверки** | Позволяет AI заставить b4 загрузить домен и запустить Дискавери, а это реальный трафик с роутера. | Выкл |
| **Настройка клиента** | Запись для AI-приложения с адресом и токеном. | - |

## Хаб сообщества {#community-hub}

Подключение к хабу сообщества, где пользователи b4 публикуют сеты и сообщают, работают ли они. Карточка подробно описана в разделе [Хаб сообщества](../community/index.md#включение).

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| **Включить хаб сообщества** | Добавляет страницу **Сообщество**, ежечасную синхронизацию и раздел **Поделиться с другими пользователями b4** в редакторе сета. | Выкл |
| **Зеркала хаба** | Адреса одного и того же хаба, по одному в строке, перебираются по порядку. Пусто - `https://hub.b4core.app`. | Пусто |
| **Публичный ключ хаба** | Только для собственного хаба со своим ключом. Ключ `hub.b4core.app` встроен. | Пусто |

**Состояние хаба** показывает каталог, последнюю синхронизацию с её ошибкой и адреса хаба, а **Синхронизировать** запускает синхронизацию сразу. **Авторский ключ** показывает ключ, которым подписываются сеты и отчёты с этого роутера. **Показать код восстановления** даёт код, который переносит этот ключ на другой роутер, а **Восстановить по коду** принимает его там.
