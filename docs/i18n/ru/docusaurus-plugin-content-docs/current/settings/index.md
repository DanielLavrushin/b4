## Сохранение и перезапуск {#saving}

Кнопки в заголовке страницы действуют на все вкладки сразу:

- **Сохранить** сохраняет изменения всех вкладок.
- **Отменить изменения** после подтверждения отбрасывает несохранённые изменения.
- **Обновить** заново загружает конфигурацию из b4 и тоже отбрасывает несохранённые изменения.

Пока есть несохранённые изменения, рядом с заголовком **Конфигурация** виден чип **Изменено**, а вкладка с изменением отмечена точкой.

Большинство изменений применяется при сохранении. Некоторые поля вкладок **Основные** и **Система**, например **Режим захвата** или **Порт** веб-сервера, применяются только после перезапуска b4. Подвкладка с таким изменением показывает значок перезапуска с подсказкой **Применится после перезапуска**, а в заголовке появляется предупреждение **Часть изменений требует перезапуска B4**. После сохранения уведомление предлагает кнопку **Перезапустить сервис**.
