# Настройки

Настройки b4 разделены на несколько вкладок:

- [Основные](./core) - сеть, очередь, функции, логирование, прокси, устройства
- [Геоданные](./geodata) - базы GeoSite и GeoIP
- [Безопасность](./security) - авторизация, HTTPS
- [Пэйлоады](./payloads) - генерация и управление TLS-пэйлоадами для faking
- [MCP-сервер](./mcp) - доступ внешнего ИИ-приложения к состоянию b4
- [Дискавери](./discovery) - таймауты, DNS-серверы, эталонный домен
- [Бэкап](./backup) - резервное копирование и восстановление

Изменения в настройках применяются после нажатия кнопки сохранения. Некоторые параметры (MTProto, очередь) требуют перезапуска сервиса. [SOCKS5-прокси](./core#socks5-прокси) - нет: он сам перепривязывает слушающий сокет, а учётные данные и список [разрешённых источников](./core#разрешённые-источники) применяет при сохранении.
