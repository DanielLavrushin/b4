b4 принимает флаги командной строки, и они имеют приоритет над значениями из [конфигурационного файла](./config.md).

Флаг переопределяет настройку только на один запуск. Когда b4 сохраняет конфигурацию, настройка, пришедшая из флага, сохраняется с тем значением, которое уже было в файле.

## Основные

| Флаг | Описание | По умолчанию |
| --- | --- | --- |
| `--config` | Путь к файлу конфигурации | Определяется автоматически, на большинстве систем `/etc/b4/b4.json` |
| `--verbose` | Уровень логирования: `debug`, `trace`, `info`, `silent` | `info` |
| `-v`, `--version` | Показать версию и выйти | - |
| `--clear-tables` | Удалить правила iptables/nftables, созданные b4, и выйти | - |

## Очередь и обработка

| Флаг | Описание | Настройка | По умолчанию |
| --- | --- | --- | --- |
| `--queue-num` | Первый номер очереди netfilter | `queue.start_num` | `537` |
| `--threads` | Количество рабочих потоков | `queue.threads` | `4` |
| `--mark` | Метка очереди, см. [Метки пакетов](../guides/marks.md) | `queue.mark` | `32768` |
| `--ipv4` | Обрабатывать IPv4-трафик | `queue.ipv4` | `true` |
| `--ipv6` | Обрабатывать IPv6-трафик | `queue.ipv6` | `false` |

`--ipv6` - это переключатель **Поддержка IPv6** в **Настройки > Основные > Движок пакетов**. Он определяет, обрабатывает ли IPv6 сам b4, а не пользуется ли им роутер. Когда он выключен, IPv6-соединения проходят через роутер без участия сетов. В режиме NFQUEUE сеты, у которых включено [Убирать ключи ECH из ответов DNS](../dns.md#удаление-ключей-ech), всё равно убирают ключи ECH из DNS-ответов по IPv6. См. [Раздел `queue`](./config.md#раздел-queue).

## Файрвол

| Флаг | Описание | Настройка | По умолчанию |
| --- | --- | --- | --- |
| `--skip-tables` | Не создавать правила iptables/nftables при запуске | `system.tables.skip_setup` | `false` |
| `--tables-monitor-interval` | Как часто проверять и восстанавливать правила, в секундах. С NFQUEUE `0` отключает проверку; в режиме TUN интервал не меньше 10, и `0` её не отключает | `system.tables.monitor_interval` | `10` |

## Логирование

| Флаг | Описание | Настройка | По умолчанию |
| --- | --- | --- | --- |
| `-i`, `--instaflush` | Сбрасывать записи лога немедленно | `system.logging.instaflush` | `true` |
| `--syslog` | Дублировать строки лога в syslog | `system.logging.syslog` | `false` |
| `--log-dir` | Каталог для файлов логов b4. Пустое значение отключает запись в файлы | `system.logging.directory` | `/var/log/b4` |

## Веб-сервер

| Флаг | Описание | Настройка | По умолчанию |
| --- | --- | --- | --- |
| `--web-port` | Порт веб-интерфейса. `0` отключает его | `system.web_server.port` | `7000` |

## Переменные окружения {#environment-variables}

| Переменная | Описание | Настройка |
| --- | --- | --- |
| `GOMEMLIMIT` | Лимит памяти среды выполнения Go. Пока переменная задана, b4 не применяет [Лимит памяти](../settings/system.md#service-settings) | `system.memory_limit` |

`GOMEMLIMIT` записывается в формате среды выполнения Go, а не поля: число байт, например `268435456` или `256MiB`, либо `off`. Значение вроде `256m` не даёт b4 запуститься.

## Примеры

Свой конфигурационный файл и debug-логирование:

```bash
b4 --config /opt/etc/b4/b4.json --verbose debug
```

Удаление правил файрвола, созданных b4:

```bash
b4 --clear-tables
```

Запуск без автонастройки файрвола, с ручным управлением правилами:

```bash
b4 --skip-tables
```

Обработка IPv6 только на этот запуск, без правки конфигурационного файла:

```bash
b4 --ipv6
```
