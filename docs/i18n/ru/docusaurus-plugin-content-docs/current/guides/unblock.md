[Дискавери](../discovery.md) ищет стратегию обхода, с которой заблокированный сайт открывается, и превращает её в [сет](../sets/index.md). Если ни одна стратегия не помогает, сайт можно направить через VPN или прокси.

## Требования

- b4 работает: поле **Состояние** на [дашборде](../dashboard.md) показывает **Работает**.
- Трафик устройств доходит до b4: график **Активность** на дашборде показывает соединения, пока устройствами пользуются.
- Адрес сайта или страницы на нём, которая не открывается.

## Настройка

1. Откройте **Дискавери**.
2. Введите сайт в поле **Сайт или URL**, например `youtube.com`, и нажмите Enter. Сайты одного сервиса, например `youtube.com` и `googlevideo.com`, можно добавить вместе.
3. Нажмите **Начать**. Запуск занимает от одной до десяти минут.
4. На карточке со стратегией нажмите **Применить как сет**.
5. Выберите **Создать новый сет**, проверьте **Название сета** и нажмите **Создать сет**.

Новый сет сразу включён. Для первого запуска обычно подходят значения по умолчанию в разделе **Параметры**, а их поля описаны на странице [Дискавери](../discovery.md#параметры).

## Проверка результата

1. Откройте сайт на устройстве за роутером.
2. Откройте дашборд. Панель **Сеты** показывает новый сет и число соединений, совпавших с ним за последний час.
3. Откройте **Трафик**. У соединений сайта в столбце **Сет** указан новый сет.

Если сработало несколько стратегий, **Взять вместо неё** под **Сработали ещё N стратегий** или в [истории](../discovery.md#история) Дискавери пробует другую. Её диалог предлагает записать стратегию в сет, который уже обрабатывает сайт, поэтому второй сет не нужен.

## Если не работает

Бейдж на карточке говорит, почему стратегия не найдена:

| Бейдж | Причина и решение |
| --- | --- |
| **адрес заблокирован** | Соединения со всеми адресами сайта не проходят, и стратегия обхода не поможет. Сайту нужен [VPN](./vpn.md) или [прокси](./proxy.md). |
| **перехвачен шлюзом** | На соединение отвечает сам первый узел перед хостом b4. Если это другой роутер, b4 должен работать на нём, либо хост b4 нужно исключить из его перенаправления. Если b4 работает на основном роутере, поможет только прокси. |
| **имя не резолвится** | У имени нет адреса, как бывает при опечатке в домене. |
| **ссылка отвечает 400** | Ссылка получает HTTP 400 даже без b4. Нужна ссылка на страницу или файл, которые отдаёт сайт. |
| **ничего не найдено** | Иногда помогает новый запуск, где **Версия TLS для проверок** - **TLS 1.2**, или запуск с захваченным ClientHello. Иначе остаётся [VPN](./vpn.md) или [прокси](./proxy.md). |

[DPI Детектор](../detector.md) показывает, как провайдер блокирует сайт: сбрасывает соединения, отбрасывает их, подменяет ответы DNS или обрывает длинные передачи. Он проверяет много сайтов сразу, а **Починить N через Дискавери** открывает Дискавери с уже подставленными заблокированными сайтами.

Если сет создан, а сайт всё равно не открывается:

- В столбце **Сет** на странице **Трафик** указан другой сет: сайт обрабатывает он, и новая стратегия там не действует. Если применить результат через **Записать стратегию в существующий сет** с этим сетом, стратегия окажется там, где она действует.
- Браузер может открывать сайт по QUIC (HTTP/3), а Дискавери его не проверяет. **Блокировать QUIC (форсировать TCP)** на вкладке [UDP](../sets/udp.md) сета переводит браузер на TCP.
- Браузер может подключаться по другой версии IP, чем запуск, например по IPv6, когда запуск проверял IPv4. Новый запуск, где **Версия IP для проверок** совпадает с версией браузера, проверяет сайт так же, как его открывает браузер.
- Страница открывается без стилей или изображений: другие хосты, которые их отдают, тоже могут быть заблокированы. Карточка результата перечисляет те из них, которые открывает стратегия, как [хосты страницы](../discovery.md#page-hosts). **Применить** в истории Дискавери предлагает их снова.
- Сайт открывался, а потом перестал: в руководстве [Поддержание работы сетов](./keep-working.md) показано, как мониторинг сам ищет новую стратегию.

Полный список проверок, от самой быстрой к самой долгой, собран в разделе [Сайт не открывается](../troubleshooting/index.md#a-site-does-not-open).
