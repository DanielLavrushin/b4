Навыки b4 - это инструкции, которым ИИ-ассистент следует, пока работает с инструментами [MCP-сервера](../settings/mcp.md) b4. Навык записан в открытом формате [Agent Skills](https://agentskills.io/). Навыки опубликованы в репозитории [b4-agent-skills](https://github.com/DanielLavrushin/b4-agent-skills).

## Навыки

| Навык | Что делает |
| --- | --- |
| **b4-connect** | Подключает ИИ-приложение к MCP-серверу b4 и чинит подключение, когда инструментов b4 нет: запись в настройках приложения, токен, ошибки сертификата, переподключение после включения переключателя. Работает без инструментов b4. |
| **b4-troubleshoot** | Выясняет, почему не работает сайт, приложение или сам b4: сайт не открывается, Дискавери ничего не находит, проблема началась после обновления, b4 конфликтует с функциями прошивки или другим прокси. |
| **b4-unblock-site** | Подтверждает блокировку проверкой сайта средствами самого b4, с согласия пользователя запускает Дискавери и применяет одобренный результат как сет. Затем снова проверяет сайт и говорит, как отменить изменение. Останавливается, если роутер и так открывает сайт. |
| **b4-proxy-routing** | Настраивает или чинит сеты, которые отправляют сайты или устройства через VPN-интерфейс или вышестоящий прокси SOCKS5, и определяет, какой сет забирает соединение. |
| **b4-find-app-hosts** | Находит, к каким хостам и по каким протоколам обращается приложение на одном устройстве, например YouTube на телевизоре, голос в Discord или игра. Сообщает, видит ли b4 этот трафик, какой сет его забирает и что добавить в сет. Другие устройства в ответ не попадают. |
| **b4-report-issue** | Пишет короткий отчёт об ошибке для issues b4 на GitHub без имени роутера, адресов и других личных данных. Сначала проверяет, не исправлена ли проблема в более новом выпуске. Без инструментов b4 работает по тексту, вставленному в чат. |

Каждый навык велит ассистенту:

- сначала читать состояние b4 и описание настройки в самом b4, а потом отвечать;
- проверять сайт, запускать Дискавери или менять настройку только по просьбе и только при включённом соответствующем переключателе;
- говорить, что сайт открывается, только после успешной проверки этого сайта средствами b4;
- не выносить в ответы и отчёты трафик других устройств и личные данные роутера.

## Требования

- MCP-сервер b4 включён и подключён к ИИ-приложению, как описано на странице [Подключение ИИ-ассистента](../settings/mcp.md). Для чтения состояния b4 больше ничего не нужно.
- Проверять сайты и запускать Дискавери ассистент может только при включённом **Разрешить активные проверки**, а менять настройки и сеты - при включённом **Разрешить изменение настроек**. Оба переключателя находятся на карточке **MCP-сервер** в разделе **Настройки > Интеграции**, см. [Изменение настроек](../settings/mcp.md#изменение-настроек).
- ИИ-приложение из таблицы ниже, которое загружает навыки и работает на компьютере, откуда доступен роутер.

## ИИ-приложения

| Приложение | Работает с навыками | Примечание |
| --- | --- | --- |
| Claude Code | да | Установка через skills CLI или как плагин. |
| Claude Desktop | да | Вкладка **Code** работает как Claude Code. В чате плагин устанавливается в **Customize > Plugins**, а MCP-сервер b4 добавляется в файл конфигурации приложения через локальный мост, например [mcp-remote](https://github.com/geelen/mcp-remote). Коннекторы, добавленные в настройках, подключаются из облака Anthropic и не достают до роутера. |
| Приложение ChatGPT для компьютера | да | Установка как плагин. MCP-сервер b4 добавляется в конфигурацию MCP, которая у приложения общая с Codex CLI. |
| Codex CLI, Gemini CLI, Cursor, VS Code с GitHub Copilot | да | Установка через skills CLI. |
| Antigravity CLI | да | Плагин b4 загружается вместе с навыками. |
| claude.ai, ChatGPT в браузере | нет | Они подключаются к MCP-серверам из облака компании-разработчика и не достают до роутера в домашней сети. |
| Настольные приложения LM Studio и Jan | нет | Пользуются инструментами MCP-сервера b4 без навыков. |
| Ollama | нет | Сама по себе не подключается к MCP-серверам. |
| Карточка **AI-помощник** в b4 | нет | Объясняет настройки в веб-интерфейсе и навыками не пользуется. |

## Установка

### Через skills CLI

Для skills CLI нужен [Node.js](https://nodejs.org/).

1. Откройте терминал в папке, с которой работает ИИ-приложение.
2. Выполните:

   ```sh
   npx skills add DanielLavrushin/b4-agent-skills
   ```

3. Выберите навыки и ИИ-приложения, когда команда спросит.

С ключом `-g` навыки устанавливаются для текущего пользователя, а не для одной папки. Параметры команды задают ответы заранее, например все навыки для Claude Code:

```sh
npx skills add DanielLavrushin/b4-agent-skills --skill '*' -a claude-code -y
```

Другие имена приложений: `codex`, `gemini-cli`, `cursor` и `github-copilot`.

### Как плагин Claude Code

В Claude Code:

```text
/plugin marketplace add DanielLavrushin/b4-agent-skills
/plugin install b4@b4-agent-skills
```

Из терминала:

```sh
claude plugin marketplace add DanielLavrushin/b4-agent-skills
claude plugin install b4@b4-agent-skills
```

### В приложении ChatGPT для компьютера

Маркетплейс добавляется через Codex CLI.

1. Выполните в терминале:

   ```sh
   codex plugin marketplace add DanielLavrushin/b4-agent-skills
   ```

2. Перезапустите приложение ChatGPT для компьютера.
3. Откройте **Plugins**, выберите источник `b4-agent-skills` и установите `b4`.

## Как пользоваться

Достаточно запроса обычными словами: приложение само загружает подходящий навык. Примеры:

- «после обновления b4 перестал открываться discord.com»
- «сделай, чтобы meduza.io открывался через b4»
- «пусти youtube.com через интерфейс wg0»
- «к каким серверам обращается Discord на моём компьютере и обрабатывает ли их b4?»
- «помоги написать отчёт об ошибке для b4»
- «ИИ-приложение не видит инструменты b4»

В Claude Code навык можно вызвать и по имени, например `/b4-troubleshoot`. С плагином имя - `/b4:b4-troubleshoot`.

## Проверка результата

На вопрос «работает ли b4?» ассистент называет версию b4, когда подключение к MCP-серверу установлено. В Claude Code вызов навыка по имени, например `/b4-troubleshoot`, показывает, установлены ли навыки.

## Если не работает

- **Приложение не загружает навыки.** Приложение не поддерживает навыки (см. таблицу), или skills CLI установил их в папку, которую приложение не открывает. С ключом `-g` навыки устанавливаются для всех папок.
- **Приложение не видит инструменты b4.** Просьба подключиться к b4 загружает навык b4-connect, которому инструменты b4 не нужны. Частые причины перечислены в разделе [Если не работает](../settings/mcp.md#если-не-работает) страницы о MCP.
- **Ассистент говорит, что не может проверить сайт или изменить настройку.** Нужный переключатель выключен, или приложение подключилось до его включения. Повторное подключение приложения к MCP-серверу загружает текущий список инструментов.
- **Проблема не решилась.** Ассистент перечисляет, что приложить к отчёту, а b4-report-issue его пишет. Куда отправить отчёт, описано на странице [Сообщение о проблеме](../troubleshooting/reporting.md).
