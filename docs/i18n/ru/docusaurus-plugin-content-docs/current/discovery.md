Дискавери ищет стратегию обхода для сайтов из поля ввода или для страниц одного сета. Результат становится новым [сетом](./sets/index.md) или записывается в существующий. Настроенные сеты во время поиска продолжают работать.

Первый запуск разобран в руководстве [Обход блокировки сайта](./guides/unblock.md), а в [Поддержании работы сетов](./guides/keep-working.md) показано, как мониторинг запускает Дискавери сам. Подробно о запуске - на странице [Как Дискавери ищет стратегию](./internals/discovery.md).

![Ввод и параметры Дискавери](/img/discovery/ru/20261003230100.png)

## Ввод

**Сайт или URL** принимает домены или полные URL через запятую или с новой строки. Домен запрашивается как `https://<домен>/`, URL - как указан. Локальные и частные адреса отклоняются.

**Поиск стратегии для сета** запускает Дискавери для одного сета и заполняет поле его [адресами Дискавери](./sets/discovery.md#адреса-дискавери) или предложениями. Запуск для сета проверяет не больше пяти адресов. Сет, который направляет трафик в прокси или интерфейс, выбрать нельзя. Если адрес из поля обрабатывает другой сет, предупреждение называет этот сет. Пункт **Найти стратегию** в меню карточки сета или на вкладке **Дискавери** редактора открывает эту страницу с уже выбранным сетом.

### Параметры

Обычно значения по умолчанию менять не нужно.

| Параметр | Что делает | По умолчанию |
| --- | --- | --- |
| **Проверять подмену DNS** | Сравнивает адрес каждого сайта с ответом доверенного резолвера, добавляет исправление DNS для подменённого адреса и ищет [альтернативные адреса](#альтернативные-адреса). Без проверки запуск короче, если DNS заведомо честный. | Вкл. |
| **Доверенный DNS-сервер** | Резолвер, которому доверяет проверка DNS, только для этого запуска. Пустое поле - [сервер из настроек](./settings/discovery.md#доверенный-dns-сервер). | Пусто |
| **Закреплённые адреса** | Строки в формате hosts: адрес, затем его имена. Эти имена проверяются через указанные адреса, а сет сохраняет их как [закреплённые адреса](./dns.md#закреплённые-адреса). | Пусто |
| **Остановиться на первой стратегии, которая работает для всех адресов** | Виден, когда выбран сет. Без него проверяются все стратегии: это дольше, но может найтись более быстрая. | Вкл. |
| **Сначала пробовать сеты сообщества** | Виден, пока включён [хаб сообщества](./community/index.md). Проверяет до трёх опубликованных сетов на сайт раньше встроенных стратегий. | Вкл. |
| **Сначала пробовать стратегии, которые уже срабатывали** | Победители прошлых запусков идут первыми. **Забыть их** очищает этот список. | Вкл. |
| **Подтверждать каждую стратегию** | Сколько запросов подряд стратегия должна пройти во время поиска, от 1 до 5. | 1 |
| **Версия TLS для проверок** | Ограничивает проверки и созданный сет версией TLS 1.2 или 1.3. | Auto |
| **Версия IP для проверок** | То же для IPv4 и IPv6. Виден, когда движок захвата обрабатывает обе версии. | Auto |
| **Захваченный ClientHello как содержимое фейков** | Фейковые пакеты несут ClientHello, захваченный в [Настройки > Пэйлоады](./settings/payloads.md). | Нет |

## Запуск

**Начать** запускает поиск из шести шагов: **DNS**, **Без обхода**, **Стратегии**, **Подбор параметров**, **Комбинации** и **Подтверждение**. Строка на сайт показывает, что найдено к этому моменту, а **Показать журнал** открывает журнал. Запуск занимает от одной до десяти минут в зависимости от сети.

![Запуск в процессе](/img/discovery/ru/20260905160200.png)

**Остановить и подтвердить** завершает поиск и подтверждает найденное, без подбора параметров. **Остановить** завершает запуск, который ещё ничего не нашёл. **Остановить сейчас** во время подтверждения завершает запуск сразу, а результаты остаются неподтверждёнными.

Одновременно идёт только один запуск, включая поиски [мониторинга](./watchdog.md). Поиск мониторинга виден на этой странице, но остановить его отсюда нельзя.

## Запуск для сета

Запуск для сета заканчивается одним вердиктом на весь сет, который показан над блоком **Результаты по адресам**. Первой проверяется собственная стратегия сета, **Текущая стратегия сета**, а найденная стратегия подтверждается на всех адресах вместе.

| Вердикт | Значение и что предлагает карточка |
| --- | --- |
| **одна стратегия покрывает все адреса** | **Применить к сету &lt;имя&gt;** записывает стратегию в сет, см. [Запись в существующий сет](#запись-в-существующий-сет). |
| **текущая стратегия работает** | Стратегия сета открывает все адреса. На случай, если в браузере сайты всё равно не открываются, карточка называет адреса, которые обрабатывает другой сет. Она также напоминает, что браузер может использовать QUIC (HTTP/3) или IPv6, а Дискавери их не проверяет. |
| **покрывает часть адресов** | **Всё равно применить к сету &lt;имя&gt;** записывает лучшую стратегию. **Убрать их из адресов Дискавери этого сета** удаляет непокрытые адреса. |
| **обход не нужен** | Все адреса открываются без b4, и по ним нельзя понять, работает ли сет. |
| **ничего не сработало** | Карточки ниже показывают, что произошло с каждым адресом. |
| **остановлен до результата** | Применять нечего. |

Последний запуск для сета показывает и его [вкладка Дискавери](./sets/discovery.md#последний-поиск).

## Результаты

Каждый сайт получает карточку, а в запуске для сета карточки собраны в блоке **Результаты по адресам**.

![Результаты запуска](/img/discovery/ru/20260905160300.png)

| Бейдж | Значение и что делать |
| --- | --- |
| **подтверждена 3 из 3**, **не подтверждена** | Сайт открыла стратегия, исправление DNS, [альтернативный адрес](#альтернативные-адреса) или удаление [ключа ECH](#сайты-с-ключом-ech). Карточка описывает сет, который будет создан. |
| **обход не нужен** | Сайт открывается без b4. |
| **адрес заблокирован** | Соединения со всеми известными адресами не проходят, и стратегия обхода не поможет. Сайту нужен [VPN](./guides/vpn.md) или [прокси](./guides/proxy.md). |
| **перехвачен шлюзом** | На соединение отвечает сам первый узел перед этим хостом. b4 должен работать на этом шлюзе, либо этот хост нужно исключить из его перенаправления. Если b4 и есть роутер, поможет только прокси. |
| **имя не резолвится** | У имени нет адреса, как бывает при опечатке в домене. |
| **ссылка отвечает 400** | Ссылка получает HTTP 400 даже без b4. Нужна ссылка на страницу или файл, которые отдаёт сайт. |
| **ничего не найдено** | Ни одна стратегия не сработала. Иногда помогает новый запуск с **TLS 1.2** или с захваченным ClientHello. |

Сайты с одной и той же стратегией-победителем делят одну карточку и один сет. **Сработали ещё N стратегий** перечисляет остальные стратегии, открывшие сайт, быстрые первыми, у каждой есть **Взять вместо неё**. Победитель - самый быстрый по одному запросу, а это шумная мера: стратегия из списка - столь же законный выбор.

## Применение

**Применить как сет**, **Применить** в истории и **Взять вместо неё** открывают один и тот же диалог. Он показывает будущий сет и предлагает:

- **Создать новый сет**, затем **Создать сет**: см. [Создание сета](#создание-сета).
- **Записать стратегию в существующий сет**, затем **Заменить стратегию**: см. ниже. Этот вариант выбран по умолчанию, если запуск шёл для сета или какой-то сет указывает сайт точно.
- **Добавить в &lt;имя&gt;, где уже используется та же стратегия**, затем **Добавить в сет**: сайты добавляются в этот сет.

**Копировать JSON** копирует сет, не создавая его, в формате вкладки **Импорт/Экспорт**.

### Запись в существующий сет

**Какой сет изменить** перечисляет сет запуска и включённые сеты без маршрутизации, которые уже совпадают с сайтом. **Другой сет** позволяет выбрать любой другой сет без маршрутизации. Записывается только стратегия обхода: TCP, фрагментация, фейки, а если результат их использует, DNS-перенаправление, закреплённые адреса и удаление ключей ECH. Фильтр портов, защита от RST, UDP, цели, маршрутизация и эскалация остаются как были. **Сохранить эти адреса как адреса Дискавери для сета** заодно заменяет адреса Дискавери сета.

Если сет не совпадает с сайтами, **Добавить &lt;сайты&gt; в этот сет** добавляет их и убирает из других включённых сетов. Диалог предупреждает, когда сайт на деле обрабатывает другой сет: там новая стратегия не действует.

### Создание сета

Предлагаемое **Название сета** - сайт без префикса и домена верхнего уровня. **Совпадение** позволяет сократить один сайт до родительского домена, чтобы сет покрывал и поддомены. Сайт, указанный в другом включённом сете, переносится в новый.

Новый сет появляется в начале списка и сразу включён. DNS-перенаправление или закреплённые адреса он получает только для сайта, которому они понадобились. Проверенные адреса становятся его [адресами Дискавери](./sets/discovery.md), поэтому сет можно снова проверить или поставить на мониторинг.

## Альтернативные адреса

Часть блокировок выдаёт адрес, который не принимает ни одного соединения, хотя клиенты в других регионах получают рабочие адреса. При включённом **Проверять подмену DNS** Дискавери ищет такие адреса, когда все известные адреса сайта недоступны. Сет закрепляет имя сайта за адресами, прошедшими TLS-рукопожатие, не больше трёх, и устройства получают их в ответах DNS.

Закреплённые адреса фиксируются на момент запуска. Если блокировка переезжает, новые находит новый запуск с проверкой DNS. Поиски мониторинга проверку DNS пропускают и закрепления не обновляют.

## Сайты с ключом ECH

Сайт, который публикует ключ ECH, проверяется так, как подключается браузер с этим ключом, поэтому ClientHello называет публичное имя из ключа, например `cloudflare-ech.com`. Сет нацелен и на это имя.

Если сеть отбрасывает ClientHello с ECH, а без ECH сайт открывается, карточка помечена **ECH блокируется**, а результат - **Ключи ECH убраны**. Такой сет включает [Убирать ключи ECH из ответов DNS](./dns.md#удаление-ключей-ech) и пакеты не меняет. Браузер со своим защищённым DNS всё равно отправляет ECH, и ему нужна одна из других стратегий под результатом.

## История

История хранит последний результат по каждому сайту, новые сверху.

![История Дискавери](/img/discovery/ru/20260905160400.png)

- **Применить** создаёт сет, собранный запуском, без нового запуска.
- **Повторить** запускает поиск заново для сайта или для сета, из которого пришла строка.
- **Удалить из истории** и **Очистить историю** удаляют одну строку или все.
- Строка раскрывается в список других сработавших стратегий, у каждой есть **Взять вместо неё**.
- **Пробовали** отмечает стратегию, которую уже применяли как сет, даже если сет удалён.
- **через мониторинг** и **через MCP** отмечают запуски, начатые мониторингом или ИИ-ассистентом через [MCP](./settings/mcp.md).

**Журнал последнего запуска** открывает журнал последнего запуска, в том числе после перезапуска, и позволяет скачать его текстовым файлом.
