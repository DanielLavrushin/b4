# Просмотр каталога

Страница **Сообщество** есть в навигации, пока включён хаб сообщества. Она показывает каталог, который хранит роутер: по карточке на сет, лучшие по оценке первыми.

## Строка состояния

Строка вверху показывает дату сборки каталога, число сетов, время последней синхронизации, сеть, в которой хаб видит роутер, и число отчётов, ждущих отправки. **Синхронизировать** загружает каталог и доставляет ждущие отчёты.

Два состояния заменяют список предупреждением:

| Предупреждение | Причина |
| --- | --- |
| Нет доверенного ключа хаба | Пользовательский ключ в настройках не читается. |
| Каталог истёк | Ни один хаб не отвечал две недели. Последний полученный каталог по-прежнему показан. |

## Поиск

Поле **Домен** сужает список до сетов, которые покрывают домен. Вставленный URL сводится к имени хоста. Сет совпадает через:

- точную запись домена;
- запись домена, которая покрывает его как суффикс;
- запись `regexp:`;
- категорию geosite, в которую входит домен, по базе geosite этого роутера; категория, которой на роутере нет, совпасть не может.

Каждая карточка называет запись, через которую совпала, например «покрывает через категорию youtube». С пустым полем показан весь каталог.

Порядок:

1. более близкое совпадение: точный домен, затем суффикс, затем категория;
2. более близкая сеть с отчётами: этот провайдер, затем эта страна, затем весь мир;
3. более высокая оценка;
4. большее число отчётов;
5. более свежее обновление.

## Карточка сета

![Карточка сета сообщества](/img/community/ru/20260914230100.png)

В заголовке - название, идентификатор авторского ключа, версия, семейство техник, нужная версия b4 и цели: первые домены, категории geosite и geoip, общее число доменов и адресов. Метки справа:

| Метка | Значение |
| --- | --- |
| **Применён** | Из этого сета создан локальный сет, и его стратегия не менялась. Открывает локальный сет. |
| **Применён, изменён** | Локальный сет есть, его стратегия менялась после применения. |
| **нужен payload** | Фейковые пакеты используют захваченный ClientHello. При применении файл загружается с хаба. |
| **блокировка** | [Блокирующий](../sets/blocking.md) сет: маршрутизация в режиме block. |
| **пины** | Сет закрепляет домены за фиксированными адресами. Они перечислены в **Подробнее**, а после применения - во вкладке **DNS** сета. |
| **широкий охват** | Сет нацеливает только категории geosite. Показывается без фильтра по домену. |
| **перехват всего** | Хотя бы одна запись домена - шаблон `regexp:`. |

Под описанием сводка стратегии описывает, что сет делает с пакетами, в том же виде, что и результат Дискавери. **Отчёты** рядом показывают оценку.

## Оценка

Оценка - доля отчётов, в которых сет работает, в виде «работает у N%», с числом отчётов, числом приславших их роутеров и датой последнего. Страница показывает ближайшую сеть, в которой отчётов достаточно:

1. **от вашего провайдера**: роутеры, которых хаб видел в том же ASN, что и этот роутер;
2. **из вашей страны**: роутеры из той же страны;
3. **со всего мира**: все роутеры.

Отчётов достаточно, когда из сети сообщили хотя бы два роутера и их отчёты вместе весят не меньше единицы. До первой синхронизации, когда хаб сообщает роутеру его сеть, показываются только отчёты со всего мира. Сет ниже порога во всех сетях показывает «отчётов пока нет».

Отчёты взвешены, и вес со временем убывает; правила описаны в разделе [Отчёты и жалобы](./feedback.md#как-отметки-складываются-в-оценку). Сет, который перестал работать, опускается через пару недель после первых отметок «не работает», сколько бы он ни набрал раньше. Сет с двумя отметками «работает» и ничем больше показывает 75%, а не 100%.

:::info
Оценка описывает чужие сети. DPI отличается между регионами одного провайдера и меняется без предупреждения. Кнопка **Проверить** на применённом сете, описанная в разделе [Применение сета](./applying.md#проверка-применённого-сета), проверяет сет на этом подключении.
:::

## Подробнее

**Подробнее** открывает всё, что каталог хранит о сете: оценку и сеть, к которой она относится, идентификатор авторского ключа, версию с нужной версией b4 и версией, на которой сет собран, движок захвата автора, даты создания и обновления, отпечаток стратегии, полный список доменов, категорий и адресов, сводку стратегии, файлы payload с размерами и JSON сета с кнопкой копирования. **Применить** и **Пожаловаться** доступны в диалоге так же, как на карточке.

Ссылка на сет, которого нет в локальном каталоге, например ещё ждущий модератора, открывает диалог с пометкой об этом.
