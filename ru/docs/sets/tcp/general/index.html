Основные

Подвкладка Основные вкладки TCP содержит настройки, которые действуют при любом методе разделения и фейкинга.

Лимиты и фильтры​

ПолеЧто делаетПо умолчанию
Лимит пакетов соединенияСколько пакетов в начале каждого соединения обрабатывает b4. TLS-рукопожатие укладывается в первые несколько, а следующие пакеты проходят без изменений. Не может превышать глобальный лимит в Настройки > Основные.19
Задержка сегмента 2Задержка между частями, которые отправляет b4, в миллисекундах. Если задан диапазон, каждое соединение выбирает из него случайное значение.0
Фильтр портовПорты назначения, к которым применяется сет, например 443 или 80,5222,8000-9000. Пустое поле - все порты, которые перехватывает b4. Порт 443 b4 перехватывает всегда и добавляет к нему порты, указанные в любом сете.Пусто
Удалить опции SACKУбирает опцию Selective Acknowledgment из TCP-заголовков. Некоторые DPI по ней восстанавливают порядок фрагментов.Выкл.
Пустая строка перед методом HTTPДля обычного HTTP на порт 80: перед запросом добавляется пустая строка, а User-Agent укорачивается на два символа, чтобы длина не изменилась. Инспекция, которая ждёт метод в начале запроса, перестаёт находить заголовок Host. Нужен заголовок User-Agent, подходит для серверов nginx.Выкл.

Дублирование пакетов​

Для провайдеров, которые замедляют трафик, отбрасывая часть исходящих пакетов на определённые диапазоны адресов, например на подсети Telegram. b4 отбрасывает исходный пакет и вместо него отправляет несколько копий.

ПолеЧто делаетПо умолчанию
Включить дублирование пакетовОтправляет каждый пакет TCP-соединений сета несколькими копиями. К дублируемым пакетам остальные техники обхода сета не применяются.Выкл.
Количество копийСколько копий отправлять, от 1 до 10.3

На странице Трафик дублированные пакеты отмечены меткой dup.

Обнаружение блокировки по IP​

Некоторые адреса серверов блокируются на уровне IP: до сервера ничего не доходит, и никакая стратегия обхода не помогает. CDN часто отдаёт в DNS несколько адресов, из которых заблокированы лишь некоторые, и сайт работает или зависает в зависимости от того, какой адрес выбрало устройство. Обнаружение находит такие адреса, а страница Трафик отмечает их соединения меткой ip. Остальные поля появляются, когда обнаружение включено.

ПолеЧто делаетПо умолчанию
Включить обнаружение блокировки по IPОбнаруживает адреса, которые не отвечают, и реагирует на них.Выкл.
Исправлять DNS-ответыДополнительно убирает недоступные адреса из DNS-ответов. Если недоступны все адреса, отдаётся последний, который для этого домена работал.Выкл.
Обнаруживать SYN без ответаЛовит блокировки по адресу, при которых соединение вообще не открывается.Вкл.
Порог SYNСколько попыток соединения без ответа нужно, чтобы роутер сам проверил адрес. Ничего не происходит, пока не провалится и эта проверка.3
Порог повторных передачСколько безответных повторов ClientHello нужно, чтобы признать адрес заблокированным. Это случай блокировки, которая пропускает соединение, а потом поглощает рукопожатие. Низкий порог может принять медленный сервер за блокировку.3
Таймаут обнаруженияПризнаёт адрес заблокированным и тогда, когда на первую попытку столько миллисекунд нет ответа.3000
TTL исправленного ответаTTL в исправленных DNS-ответах, в секундах. С коротким значением устройства быстро подхватывают восстановившийся адрес.60
Кэшировать заблокированные IPЗапоминает заблокированные адреса, чтобы новые соединения к ним сразу сбрасывались, без ожидания.Вкл.

Сколько адрес остаётся отмеченным, задаёт Интервал перепроверки (секунды) в Настройки > Основные.

MSS Clamping​

Ограничивает максимальный размер TCP-сегмента (MSS) для соединений сета. С меньшим MSS клиент отправляет ClientHello несколькими сегментами, а собрать их обратно умеет не всякий DPI.

ПолеЧто делаетПо умолчанию
Включить MSS для сетаВключает ограничение для сета. Доступно, когда в сете есть цель по IP, GeoIP, ASN или исходному устройству.Выкл.
Размер MSS (байт)MSS, от 10 до 1460. При включении переключателя подставляется 88.88

MSS выставляется в первом пакете соединения, раньше, чем становится известно имя сервера. Поэтому где действует ограничение, решают только цели по IP, GeoIP, ASN и исходным устройствам. Домены, категории GeoSite и фильтр версии TLS здесь не участвуют.

Цели сетаК чему применяется ограничение
IP-адреса, категории GeoIP или ASNК соединениям на эти адреса
Только исходные устройстваК каждому соединению на порт 443 с этих устройств, куда бы оно ни шло
И то и другоеК соединениям с этих устройств на эти адреса

Сет, у которого цели по IP, GeoIP и ASN пока не дают ни одного адреса, не устанавливает ограничение, пока они не разрешатся. Устройству, добавленному вручную, нужен фиксированный адрес, чтобы им можно было сузить ограничение.

88 - значение, которое интерфейс предлагает для смарт-ТВ на YouTube. В каждом сегменте тогда не больше 88 байт, поэтому большие загрузки идут медленно, и если соединение работает, но еле ползёт, следующий шаг - значение побольше. Чтобы замедлить HTTPS одного устройства без сета, то же самое делает MSS у устройства. MSS сета имеет приоритет над MSS устройства и глобальным для тех соединений, которые он покрывает.
