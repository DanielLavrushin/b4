Дискавери

Вкладка Дискавери в редакторе сета содержит страницы, которые Дискавери проверяет для сета, последний поиск для него и переключатель, ставящий сет на мониторинг. Порядок настройки описан в руководстве Поддержание работы сетов.

Сет, который направляет трафик в прокси или интерфейс, стратегию обхода не применяет, поэтому для него вкладка доступна только для чтения.

Адреса Дискавери​

Поле Адрес добавляет страницу, которую Дискавери запрашивает при поиске стратегии для сета. Мониторинг проверяет те же страницы.

ПравилоЧто происходит
Не больше 5 адресов, по одному на хостКогда список заполнен, поле отключается.
ДоменПревращается в https://<домен>/.
Полный URLСохраняется вместе с путём.
Только адреса http и https публичных хостовЛокальные и частные адреса отклоняются.

Стратегия, найденная на этих страницах, действует на все домены сета, хотя проверялись только они. Для сета на основе категории GeoSite это все записи категории. Полезны страницы, которые представляют сет, например главная страница каждого сервиса из него, и страницы, которые без b4 не открываются. Страница, открывающаяся без b4, не показывает, работает ли сет.

Сет, созданный Дискавери, сохраняет адреса, на которых была найдена стратегия. Сохранить эти адреса как адреса Дискавери для сета в диалоге применения Дискавери записывает проверенные адреса в существующий сет. Отслеживать через <сет> в старом списке доменов мониторинга добавляет адрес домена.

Адреса Дискавери описывают локальную сеть и остаются на роутере. В сете, переданном другим или опубликованном в хабе сообщества, их нет, а обновление из хаба сохраняет локальные адреса. JSON вкладки Импорт/Экспорт переносит адреса, но не переключатель мониторинга.

Предложения​

Предложить загружает до десяти адресов-кандидатов, по одному на хост. У каждого указан источник:

  • Сохранён для этого сета;
  • Из прошлого поиска для этого сета;
  • Из списка сайтов DPI Детектора - сайты из списка DPI Детектора, которые попадают в сет;
  • Домен из списка сета;
  • Известная страница сервиса из категорий geosite сета.

Добавить вносит предложение в список. Если хост обрабатывает другой сет, предложение называет его: стратегия, записанная в этот сет, на такой хост не действует. Сет, цели которого - только большие списки вроде ru-blocked, обычно предложений не получает, и страницу приходится добавить вручную.

Предложить и Найти стратегию работают только для сохранённого сета.

Поиск стратегии​

Найти стратегию открывает Дискавери с выбранным сетом и его адресами в поле ввода. Несохранённые изменения сета при переходе теряются. То же делает пункт Найти стратегию в меню карточки сета на странице Сеты.

Мониторинг​

Поддерживать работу сета с помощью мониторинга ставит сет на мониторинг. Тогда адреса Дискавери сета проверяются по расписанию. Если они продолжают не открываться, мониторинг ищет новую стратегию, записывает её в сет, снова проверяет адреса и отменяет изменение, если они по-прежнему не открываются.

Кроме того, в разделе Настройки > Дискавери должен быть включён переключатель Включить мониторинг. Пока он выключен, переключатель сета может оставаться включённым, но ничего не проверяется.

УсловиеЕсли не выполнено
Сет включёнПереключатель остаётся включённым, а сет не проверяется, пока его не включат.
У сета есть адреса ДискавериПереключатель остаётся включённым, но ничего не проверяется, пока не добавлен адрес.
Сет не маршрутизирует трафикПереключатель выключается при сохранении сета.
Сет не ограничен отдельными устройствами через список включенияПереключатель выключается при сохранении сета. Собственная проверка роутера идёт без MAC устройства и под такой сет не попадает.
У сета есть цели-домены или категории GeoSiteПереключатель остаётся включённым, но сет не проверяется. Сет из одних IP-адресов, категорий GeoIP или ASN нельзя проверить по имени.

Подпись под переключателем называет невыполненное условие.

Когда сет сохранён с включённым переключателем, а Включить мониторинг включён, вкладка показывает статус мониторинга сета и время последней проверки. Там же видны последнее восстановление с записанной стратегией и кнопка Открыть мониторинг. На странице Сеты карточка отслеживаемого сета несёт бейдж Мониторинг цвета этого статуса.

Восстановление может изменить сет, пока в редакторе открыта его старая копия. Сохранение такой копии отклоняется с предложением перезагрузить данные, а несохранённые изменения при перезагрузке теряются.

Последний поиск​

Последний поиск для этого сета показывает самый свежий запуск Дискавери для сета: вердикт, время окончания, найденную стратегию и то, какие адреса она покрыла. Открыть в Дискавери открывает Дискавери с выбранным сетом.
