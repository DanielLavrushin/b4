Трафик

Страница Трафик показывает соединения, которые разбирает b4, по мере их появления: протокол, домен, адрес назначения, устройство и совпавший сет. По ней видно, доходят ли соединения сайта до сета, и с неё домены, адреса и сети добавляются в сеты. Раздел DNS для сетов проверяет на ней ответы DNS.

b4 видит только первые пакеты каждого соединения - в пределах лимитов на соединение из раздела Настройки > Основные > Движок пакетов. Поэтому одно соединение даёт несколько записей, а число пакетов ничего не говорит о скорости или объёме. DNS-запросы, совпавшие с сетом, тоже попадают на страницу вместе с решением b4 по каждому, пока Уровень логирования - Инфо или подробнее. Соединение, которое прокси-сет отправляет в свой upstream, появляется один раз.

Страница открывается в режиме Группы. Сырой поток в правом верхнем углу показывает вместо них отдельные пакеты.

Группы​

Пакеты сводятся в группы по устройству, протоколу и домену, а пакет без домена - по адресу назначения. Группы накапливаются, пока открыта страница. Уход со страницы, переключение на Сырой поток и очистка начинают их заново.

СтолбецЧто показывает
ПротоколTCP или UDP
ДоменДомен из рукопожатия или (без домена), версию TLS (1.2, 1.3) и метки. У домена вне сетов есть кнопка +, см. Добавление доменов в сеты
НазначениеПоследний адрес назначения, +N, если адресов было несколько, и его ASN
СетСет, совпавший по домену, и сет, совпавший по IP, если это другой сет
ИсточникУстройство, см. Устройства
АктивностьЧисло пакетов по секундам за последнюю минуту
ПакетыЧисло пакетов в группе
ДавностьВремя с последнего пакета

Клик по строке открывает панель Детали: активность, число пакетов, время от первого пакета до последнего, источник, все адреса назначения группы и совпавшие сеты. Для домена вне сетов там же есть Добавить домен в сет.

Провайдеры могут блокировать TLS 1.2 и TLS 1.3 по-разному, а сет можно ограничить одной версией TLS на вкладке Цели.

Панель управления​

ЭлементДействие
Поле фильтраОставляет подходящие строки, см. Фильтр
30s, 1m, 5m, 15m, ВсёПоказывает группы, в которых были пакеты за этот период. По умолчанию 1m
Только без правилОставляет только группы, не совпавшие ни с одним сетом
Только домены / Все пакетыСм. Только домены и все пакеты
КорзинаОчистить пакеты, см. Пауза и очистка

Дашборд открывает эту страницу с включённым Только без правил по ссылке Домены вне сетов на панели Активность и с выбранным устройством с панели Блокировки, в обоих случаях с периодом Всё.

Устройства​

Панель Устройства слева перечисляет источники за выбранный период: давность последнего пакета, активность и число пакетов. Клик по устройству оставляет в списке только его группы, Все устройства снимает выбор. Скрыть устройства сворачивает панель. Сортировка устройств упорядочивает её По имени (по умолчанию), По последней активности или По числу пакетов.

Устройство определяется по MAC-адресу. Если MAC неизвестен, например у устройства за другим роутером, источник показывается по IP-адресу. Псевдонимы из таблицы фильтрации устройств показываются всегда. Когда там включена фильтрация или определение производителя, подставляются и имена обнаруженных устройств, а собственные адреса роутера подписываются Роутер.

Сырой поток​

Сырой поток показывает последние 1000 пакетов по одному, новые - внизу.

СтолбецЧто показывает
ВремяВремя пакета
ПротоколTCP или UDP и метки
СетСет, совпавший по IP, а если такого нет - по домену
ДоменВерсию TLS и домен. У домена вне сетов есть кнопка +
ИсточникИмя устройства или IP-адрес и порт источника
НазначениеАдрес и порт назначения, ASN и кнопку + для адреса вне сетов

Метки​

Метки отмечают особые случаи: в режиме Группы рядом с доменом, в сыром потоке и в панели Детали - рядом с протоколом.

МеткаЗначение
dupПакет продублирован, см. Дублирование пакетов
ipАдрес назначения признан заблокированным по IP. Контурная метка - адрес уже был в кэше заблокированных
банАдрес назначения забанен, b4 сбросил соединение или, для QUIC, отклонил его
blockПакет заблокировал сет блокировки
voiceПакет звонка, пропущенный без изменений: сетом, у которого в поле Звонки выбрано Пропускать начало звонков, или сетом, который обрабатывает только звонки, как следующий пакет забранного им звонка. Сам пакет, который забрал такой сет, метку voice не получает, а в столбце Сет у него указан этот сет
proxyСоединение пришло через SOCKS5-прокси b4
Значок TelegramСоединение MTProto-прокси b4, с именем секрета
Значок Telegram с надписью Мост TelegramСоединение, переправленное мостом Telegram через WebSocket
doh, forward, pin, sinkhole и другиеРешение b4 по DNS-запросу, см. DNS для сетов

Только домены и все пакеты​

Переключатель в панели управления действует в обоих режимах.

РежимЧто показывается
Только доменыПакеты с распознанным доменом. Режим по умолчанию
Все пакетыВсе разобранные пакеты, в том числе TCP-рукопожатие до ClientHello, соединения без SNI и трафик на адреса без имени

Фильтр​

Поле фильтра работает в обоих режимах.

  • + соединяет условия: должны выполниться все.
  • ! перед условием исключает совпадения.
  • поле:значение проверяет одно поле. Несколько условий на одно поле выполняются, если совпало любое из них. Пустое значение, например set:, совпадает с пустым полем.
  • Слово без поля ищется во всех полях.

Поиск не учитывает регистр и ищет подстроку. Поля обоих режимов: protocol, domain, destination, tls, flags, asn и device (синоним alias). Поле set есть только в режиме Группы, source - только в сыром потоке.

ФильтрЧто покажет
protocol:udpUDP-пакеты
domain:youtubeПакеты с «youtube» в домене
protocol:tcp+!domain:google.comTCP-пакеты, кроме доменов google.com
asn:AS13335Адреса назначения в AS13335 (Cloudflare), для которых определён ASN
flags:dnsDNS-запросы и решения b4 по ним
set:Группы, не совпавшие ни с одним сетом

Добавление доменов в сеты​

Кнопка + рядом с доменом открывает окно Добавить домен в список.

  1. Выберите домен или один из его родительских доменов: они перечислены от самого точного до самого широкого. Для rr1---sn-ab5l6ne7.googlevideo.com это само имя и googlevideo.com.
  2. В поле Целевой сет выберите один из включённых сетов или Создать новый сет и введите Название сета.
  3. Нажмите Добавить домен.

Домен в сете покрывает и свои поддомены. Сервис, который раздаёт контент со множества поддоменов, например YouTube или CDN, покрывается родительским доменом, например googlevideo.com.

Добавление адресов и сетей в сеты​

Кнопка + рядом с адресом назначения, а в сыром потоке и клик по самому адресу, открывает окно Добавить в сет. b4 выясняет через RIPEstat, какая сеть анонсирует адрес. Затем окно показывает адрес, анонсированный префикс, который его покрывает, и сеть, например AS15169 Google LLC. Если префикс анонсируют несколько сетей, одна из них выбирается в окне. У частного адреса сети нет. Неудачный поиск можно повторить кнопкой Повторить, а сам адрес можно добавить в любом случае.

Что добавить​

ВариантЧто попадает в сет
Один IPТолько этот адрес, как /32, для IPv6 - /128. Вариант по умолчанию
Анонсированный префикс, который покрывает этот адресПрефикс, например 142.250.0.0/15, если он известен и шире самого адреса
Более широкий диапазонАдрес с маской вроде /24 или /16, для IPv6 - /64 или /48. Сохраняется как сеть: 142.250.120.139/24 становится 142.250.120.0/24
Вся сетьСам ASN, см. ASN. b4 загружает его префиксы и обновляет их раз в сутки

Для всей сети окно показывает число префиксов ASN и примерное число IPv4-адресов в нём и предупреждает о большой сети так же, как редактор сета. Вариант недоступен, если в сете этот ASN уже есть. ASN, префиксы которого ещё неизвестны, добавляется всё равно, а b4 загружает их в фоне.

Сет выбирается в поле Целевой сет, как в окне для домена, а кнопка подтверждения называет то, что добавляется, например Добавить AS15169.

Когда на вкладке Настройки > Интеграции указан токен IPInfo, кнопка Обогатить через IPInfo показывает имя хоста, организацию и расположение адреса по данным ipinfo.io, а имя хоста можно добавить в домены сета.

DPI Детектор открывает то же окно из своих результатов по хостингам и CDN, где сеть затронутого провайдера уже выбрана.

ASN​

Иконка сети рядом с адресом назначения определяет сеть без открытия окна. b4 находит ASN, который анонсирует адрес, и загружает его префиксы в свой кэш ASN. После этого адреса этой сети получают метку вида AS15169 Google LLC, а фильтр asn: их находит. Все браузеры видят одни и те же метки, а ASN, на которые нацелены сеты, тоже подписывают свои адреса.

Крестик на метке удаляет этот ASN из кэша. ASN, на который ещё нацелен какой-либо сет, не удаляется: b4 называет сеты, которые его используют, и метка остаётся.

Пауза и очистка​

Круглая кнопка в правом нижнем углу ставит поток на паузу и возобновляет его. На паузе новые пакеты не собираются. Очистить пакеты - корзина в панели управления - удаляет собранные пакеты, группы и устройства.

Число рядом с пунктом Трафик в боковом меню считает пакеты, совпавшие с каким-либо сетом. Клик по Трафик в меню или очистка пакетов сбрасывает его, а на паузе оно не растёт.
