Основные

Вкладка Основные определяет, как трафик попадает в b4 и что b4 с ним делает. Некоторые поля применяются только после перезапуска, см. Сохранение и перезапуск. Как устроен движок, описано в разделе Перехват пакетов.

Движок пакетов​

Подвкладка определяет, как пакеты попадают в b4, с какими семействами адресов он работает и какую часть каждого соединения читает.

Режим захвата​

Режим захвата выбирает, как пакеты попадают в b4. Изменение применяется после перезапуска.

РежимКак пакеты попадают в b4
NFQUEUE (по умолчанию)Правила файрвола передают пакеты в b4. Обычный выбор.
TUN-интерфейсТрафик маршрутизируется через виртуальный интерфейс, который читает b4. Для ядер без модулей, нужных NFQUEUE.

Настройки TUN​

Видны, пока выбран TUN-интерфейс.

ПолеЧто делаетПо умолчанию
Аплинк-интерфейсКуда b4 отправляет обработанные пакеты. Авто (следовать маршруту по умолчанию) переключается вместе с маршрутом по умолчанию при смене WAN или VPN. Выбранный интерфейс закрепляет аплинк.Авто (следовать маршруту по умолчанию)
Шлюз аплинкаШлюз закреплённого аплинка. Если поле пустое, шлюз берётся из маршрута по умолчанию.Пусто
Адрес TUNАдрес и префикс TUN-устройства. Не должен пересекаться с подсетями LAN или VPN.10.255.0.1/30

Интерфейсы захвата​

Интерфейсы захвата видны в режиме NFQUEUE и ограничивают b4 трафиком, который уходит с роутера через выбранные интерфейсы. Пустой выбор, значение по умолчанию, охватывает все интерфейсы. Рекомендуется оставить его пустым.

VPN-клиент или туннель может увести трафик на другой интерфейс, и к трафику вне выбора сеты не применяются. Если после выбора интерфейса ничего не работает, первым делом стоит снять выбор, см. Интерфейсы захвата ни с чем не совпадают. См. также Какой интерфейс за что отвечает.

Если движок не запустился​

Если движок пакетов не запустился, веб-интерфейс работает, но трафик проходит через роутер без изменений. Причину показывают дашборд и карточка Движок пакетов. Если в ядре нет модулей, нужных NFQUEUE, помогает их установка или переключение на TUN-интерфейс. b4 сам повторяет запуск три раза в течение примерно двух минут, поэтому WAN или VPN, поднявшиеся позже b4, проблемой не становятся. Подробности - в разделе Запуск движка и повторные попытки.

Обнаружение блокировки по IP​

Обнаружение блокировки по IP включается в каждом сете отдельно, на вкладке TCP > Основные. Карточка содержит его общую настройку.

ПолеЧто делаетПо умолчанию
Интервал перепроверки (секунды)Сколько адрес, отмеченный как недоступный, остаётся отмеченным до повторной проверки. Примерно столько же занимает восстановление после снятия блокировки. С тем же интервалом проверяются закреплённые DNS-адреса.300

IPv4 / IPv6​

ПолеЧто делаетПо умолчанию
Поддержка IPv4b4 обрабатывает трафик IPv4.Вкл
Поддержка IPv6b4 обрабатывает пакеты IPv6, DNS-ответы и правила файрвола для IPv6. Пока она выключена, сеты, у которых включено Убирать ключи ECH из ответов DNS, в режиме NFQUEUE всё равно убирают ключи ECH из DNS-ответов по IPv6.Выкл
Форсировать IPv4 для совпавших доменовПока поддержка IPv6 выключена, b4 убирает IPv6-адреса из DNS-ответов для доменов, совпавших с сетом, и клиенты подключаются к ним по IPv4.Вкл
Поддержка IPv6 выключена

Если поддержка IPv6 выключена, сайт из сета, который отвечает и по IPv6, может открыться по IPv6 мимо всех сетов. Форсировать IPv4 для совпавших доменов сужает эту брешь для устройств, которые резолвят имена через роутер, см. Откат на IPv4.

Устройства​

Карточка Фильтрация устройств ограничивает обход DPI выбранными устройствами или исключает выбранные устройства из него. Что охватывает фильтр и как его настроить, описано в руководстве b4 только для выбранных устройств.

ПолеЧто делаетПо умолчанию
Включить фильтрацию устройствВключает отбор. Пока он выключен, обход DPI получают все устройства.Выкл
Исключить выбранные устройства (чёрный список)Выключено: обход DPI получают только выбранные устройства. Включено: выбранные устройства из него исключены.Выкл
Определение производителяСкачивает список производителей IEEE, около 6 МБ, чтобы называть производителя каждого устройства. Случайный MAC-адрес отображается как Private.Выкл

Доступные устройства​

Пока фильтрация включена, карточка показывает устройства из таблицы ARP роутера и устройства, добавленные вручную.

СтолбецЧто показывает
ЧекбоксВыбирает устройство.
MAC адресMAC-адрес или по IP для устройства, добавленного вручную.
IPТекущий адрес. вручную отмечает устройство, добавленное вручную, не в сети - устройство с именем, которого сейчас нет в сети.
ИмяИмя, заданное значком редактирования, иначе производитель.
MSSMSS clamping для TCP-соединений устройства на порт 443, от 10 до 1460. Действует независимо от того, включена ли фильтрация.

Ручные устройства​

Добавляет устройство, которого нет в таблице ARP, например за другим роутером, по полю IP адрес и необязательному Имя. Такое устройство сопоставляется по IP-адресу. Оно учитывается в сетах маршрутизации, в исходных устройствах сета и в своём значении MSS, но не в обходе DPI: он сопоставляет устройства только по MAC-адресам.

Файрвол​

Подвкладка задаёт, как b4 управляет своими правилами файрвола, и правила, которые он ставит помимо захвата.

Правила файрвола​

ПолеЧто делаетПо умолчанию
Пропустить настройку IPTables/NFTablesДля систем, где правила добавляют вручную. В режиме NFQUEUE b4 не ставит правил захвата, а NAT Masquerade, MSS clamping, DSCP, перехват DNS поверх TCP и Доступ из интернета не работают.Выкл
Движок файрволаБэкенд для правил b4. Автоопределение, обычный выбор, использует nftables, если они работают, иначе iptables.Автоопределение
Интервал мониторинга файрвола (секунды)Как часто b4 возвращает правила, которые удалил файрвол роутера. 0 отключает проверку в режиме NFQUEUE. В режиме TUN минимум - 10.10

Глобальный MSS Clamping​

MSS clamping задаёт максимальный размер TCP-сегмента для каждого соединения на порт 443, в том числе соединений самого роутера. ClientHello клиента тогда уходит несколькими небольшими сегментами.

ПолеЧто делаетПо умолчанию
Включить глобальный MSS ClampingВключает MSS clamping.Выкл
Размер MSSРазмер сегмента в байтах, от 10 до 1460.88

Значение устройства в списке Доступные устройства важнее глобального, а значение сета на его вкладке TCP > Основные важнее обоих.

NAT Masquerade​

Маскарад заменяет адрес источника пересылаемых пакетов адресом исходящего интерфейса. Он нужен в контейнерах и на шлюзах, где b4 пересылает трафик.

ПолеЧто делаетПо умолчанию
Включить NAT MasqueradeВключает маскарад.Выкл
Теги интерфейсовОграничивают маскарад выбранными исходящими интерфейсами, обычно аплинками. Если ничего не выбрано - все интерфейсы.Не выбраны

DSCP​

b4 может записывать значение DSCP в отправляемые пакеты, чтобы роутер перед ним отличал его трафик. Настройка описана в руководстве Передача сетов другому роутеру.

ПолеЧто делаетПо умолчанию
Задать DSCPЗаписывает Значение DSCP в пакеты, которые отправляет этот хост.Выкл
Значение DSCPОт 0 до 63. При включении переключателя подставляется свободное значение, обычно 7: оно сохраняет обычный приоритет в Wi-Fi и на роутерах с Linux.0
Теги интерфейсовИсходящие интерфейсы, пакеты которых получают значения. Если ничего не выбрано - все интерфейсы, кроме loopback.Не выбраны

Сет может записывать собственное значение в пакеты к своим адресам, см. DSCP. Такие сеты перечислены на карточке.

Значение уходит в интернет

Роутер, который читает значение, должен сбрасывать его на своём выходе в интернет. Иначе провайдер видит его в каждом соединении, которое проходит через b4.

Подвкладка содержит настройки DNS, общие для всех сетов. Сам резолвер выбирается в сете, см. DNS.

Порт слушателяЛокальный порт для DNS поверх TCP. Другое значение нужно, только если порт занят другой программой.5453

Таймаут простояСколько секунд держать открытым простаивающее TCP-соединение.30
Таймаут чтения/записиСколько секунд даётся на один запрос или ответ в открытом соединении.10
Таймаут пересылкиСколько секунд ждать резолвер клиента, если TCP-запрос не совпал ни с одним сетом.5

Подвкладка настраивает встроенный SOCKS5-прокси. Соединения через него уходят с роутера, и к ним применяются сеты, см. Соединения через встроенный SOCKS5-прокси.

ПолеЧто делаетПо умолчанию
Включить SOCKS5 проксиЗапускает прокси.Выкл
Адрес привязки0.0.0.0 - все адреса, 127.0.0.1 - только сам роутер.0.0.0.0
ПортПорт прокси.1080
Доступ из интернетаДобавляет правило файрвола, открывающее порт для любых адресов, см. Доступ из интернета.Выкл
Имя пользователя, ПарольЛогин прокси, задаются вместе. Оба поля пустые - без логина.Пусто
Разрешённые источникиАдреса клиентов, которым разрешено подключаться. Пустой список - любые адреса.Пусто

Изменение полей Включить SOCKS5 прокси, Адрес привязки или Порт перезапускает прокси и закрывает его соединения.

Разрешённые источники​

Добавить IP или CIDR добавляет адрес или диапазон, IPv4 или IPv6, а Из устройств - адрес известного устройства. Остальным адресам прокси отказывает. Клиенту на самом роутере нужна запись 127.0.0.1/32.

Chrome и Chromium не умеют входить на SOCKS5-прокси по логину, поэтому для них ограничить доступ можно только списком источников. Если заданы и логин, и список, клиенту нужно и то и другое. Список - не аутентификация: адрес можно подделать. Правила файрвола он тоже не добавляет, а убрать прокси с WAN позволяет привязка к адресу LAN.
