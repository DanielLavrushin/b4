Дискавери

На вкладке Дискавери раздела Настройки две карточки. Конфигурация тестирования задаёт время ожидания и доверенный DNS-сервер для запусков Дискавери. Мониторинг включает мониторинг и задаёт его интервалы.

Кнопка Сохранить в заголовке страницы сохраняет вкладку, см. Сохранение и перезапуск. Перезапуск ни для одного изменения не нужен. Изменение действует со следующего запуска Дискавери, а не для уже идущего.

Конфигурация тестирования​

ПолеЧто делаетПо умолчанию
Таймаут поискаПредел времени на один запрос сайта. Большее значение помогает при медленном или нестабильном соединении.5 сек
Задержка распространения конфигурацииПауза после того, как Дискавери переключился на следующую стратегию, перед запросом через неё. Большее значение помогает на слабом роутере. Столько же ждёт мониторинг после восстановления, прежде чем снова проверить сет.1500 мс

Сколько запросов подряд должна пройти стратегия, задаётся для каждого запуска параметром Подтверждать каждую стратегию в параметрах Дискавери.

Доверенный DNS-сервер​

Доверенный DNS-сервер в разделе Настройки DNS - резолвер, ответы которого Проверять подмену DNS считает верными. Дискавери сравнивает адрес каждого сайта от резолвера роутера с ответом этого сервера. Пустое поле - встроенные в b4 публичные резолверы.

ФормаТранспорт
9.9.9.9, 2620:fe::fe, 127.0.0.1:53053, udp://9.9.9.9Обычный DNS по UDP, с повтором по TCP, если ответ обрезан
tcp://9.9.9.9Обычный DNS по TCP
tcp+udp://127.0.0.1:53053Сначала UDP, по TCP - если UDP не сработал
https://dns.google/dns-queryDNS поверх HTTPS. Если в URL нет пути, добавляется /dns-query

По умолчанию используется порт 53. Обычному DNS нужен IP-адрес, а имя хоста работает только в URL https://. DNS поверх TLS напрямую не поддерживается: вместо него здесь можно указать локальный DNS-прокси, который его умеет.

Если резолвер роутера выдаёт сайту неверный адрес, предложенный сет получает исправление DNS. Сам доверенный сервер попадает в сет, если сет может им пользоваться: это публичный IP-адрес на порту 53, отвечающий по UDP и не принадлежащий этому хосту, или URL https://. Иначе сет получает встроенный резолвер, который возвращает верный адрес, или верные адреса закрепляются в сете. Журнал запуска сообщает, какой вариант выбран.

При включённом Проверять подмену DNS запуск останавливается с ошибкой, если сервер не отвечает перед его началом. То же поле в параметрах Дискавери заменяет это значение для одного запуска. Как проверка принимает решение, описано на странице Как Дискавери ищет стратегию.

Мониторинг​

Включить мониторинг включает и выключает мониторинг для всех отслеживаемых сетов и старого списка доменов. По умолчанию он выключен. Сет ставится на мониторинг на его собственной вкладке Дискавери, а переключатель здесь должен быть включён, чтобы проверялся хоть один сет.

Поля ниже видны, пока переключатель включён.

ПолеЧто делаетПо умолчанию
Интервал проверкиКак часто проверяется каждый отслеживаемый сет или домен, пока он работает.300 сек
Интервал после ошибкиКак часто сет или домен проверяется снова после неудачной проверки.60 сек
Перерыв между discoveryПауза после поиска новой стратегии перед следующей проверкой этого сета или домена.900 сек
Таймаут проверкиПредел времени на один запрос проверки.15 сек
Макс. попытокСколько неудачных проверок подряд запускают поиск новой стратегии.3

Выключение переключателя отменяет идущий поиск, и такой поиск ничего не записывает.

Старый список доменов​

Старый список доменов содержит домены, которые мониторинг проверяет по одному, см. Старый список доменов. Добавить домен добавляет домен или полный URL, а крестик на чипе удаляет запись. Тот же список редактируется на странице Мониторинг.
