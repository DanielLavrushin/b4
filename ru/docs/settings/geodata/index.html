Geodat настройки

Вкладка Geodat настройки скачивает и обновляет базы GeoSite и GeoIP. С ними сет может нацеливаться на целую категорию доменов или адресов, а не на отдельные записи, см. Добавление сайтов в сет.

GeoSite и GeoIP​

Обе базы в формате V2Ray и группируют записи по именованным категориям.

  • GeoSite (geosite.dat) группирует домены. Например, категория youtube содержит youtube.com, googlevideo.com, ytimg.com и другие домены YouTube.
  • GeoIP (geoip.dat) группирует IP-диапазоны: по странам, а в b4geoip по сервисам.

Источники​

Список Источник на каждой карточке предлагает источники, которые публикуют эту базу, и пункт Свой URL... для любого другого адреса .dat файла.

ИсточникЧто содержит
LoyalsoldierДомены и IP-диапазоны, Китай и весь мир
RUNET FreedomДомены и IP-диапазоны под российские блокировки
b4geoipIP-диапазоны по сервисам, только GeoIP

Для сетей в России рекомендуются RUNET Freedom для GeoSite и b4geoip для GeoIP. Инсталлятор предлагает их по умолчанию.

b4geoip​

GeoIP база проекта b4. Она собирается автоматически из префиксов, которые анонсирует каждая сеть, по данным RIPE NCC. База группирует адреса по сервисам, так что сет может нацелиться на одну платформу:

  • облачные провайдеры: AWS, Google Cloud, Azure, DigitalOcean, Hetzner, OVH, Scaleway, Oracle Cloud, Contabo, AEZA;
  • CDN: Cloudflare, Akamai, Fastly, CDN77;
  • игровые компании: Roblox, Valve/Steam, Sony/PlayStation, Nintendo, EA, Riot Games, Ubisoft, Epic Games, Wargaming, Bungie, Take-Two, CCP;
  • платформы: Telegram, GitHub, Apple, Adobe, Amazon, Blizzard.

Директория назначения​

ПолеЧто делаетПо умолчанию
Директория назначенияКаталог, куда Обновить и Загрузить записывают файлы, всегда под именами geosite.dat и geoip.dat. Если каталога нет, b4 его создаёт.Каталог текущих файлов, /etc/b4, если файлов нет

Поле не сохраняется кнопкой Сохранить. Новый каталог применяется при следующем Обновить или Загрузить на каждой карточке: файл записывается в новый каталог, а копия, которую b4 записал по старому пути, удаляется. До этого подсказка под полем называет оба каталога.

Карточки баз​

Карточки База данных Geosite и База данных GeoIP управляют каждая своим файлом. Чип в заголовке карточки показывает состояние:

ЧипЗначение
АктивнаФайл есть. Под путём показаны его размер и время изменения
Не найденаПуть задан, но файла по нему нет
ОтключенаПуть не задан, база не используется

Под заголовком указаны путь к файлу, или Не настроено, и URL источника. У загруженного файла вместо URL написано Локальная загрузка.

ЭлементЧто делает
ИсточникВыбирает источник из списка или Свой URL... с адресом в поле Свой URL. Выбор сохраняется, когда Обновить проходит успешно
ОбновитьСкачивает выбранный источник в директорию назначения. Сеты получают новые категории без перезапуска
ЗагрузитьЗаписывает .dat или .db файл до 500 МБ из браузера в директорию назначения. У загруженного файла нет URL источника, поэтому автообновление его не трогает
УдалитьУдаляет файл и отключает базу, см. ниже

Одновременно идёт только одна закачка. Закачка, начатая во время другой, с соседней карточки или фоновой, завершается ошибкой another geodata download is already running.

Удаление базы​

Удалить открывает диалог Удаление базы геоданных с путём к файлу. Подтверждение стирает файл и очищает путь и URL источника. База остаётся отключённой до следующего Обновить или Загрузить, автообновление её не возвращает. b4 стирает только файл с именем geosite.dat или geoip.dat. Файл с другим именем остаётся на диске, а база всё равно отключается.

Диалог перечисляет сеты, которые используют категории из этой базы. Пока такой сет есть, отключить базу нельзя. Файл стирается, но сохранение завершается ошибкой Failed to save configuration: Configuration is invalid, и следующая проверка отсутствующих файлов скачивает файл снова. Чтобы отключить базу, категории сначала убирают из этих сетов. На роутере с небольшим объёмом памяти удаление базы, которую не использует ни один сет, освобождает весь её объём.

Обновление​

Обновить заменяет базу по запросу. Фоновые закачки берут сохранённые URL источников: по расписанию группы Автообновление или чтобы восстановить отсутствующий файл.

Скачанный файл проверяется до того, как заменить текущий. Страница ошибки или блокировки, пустой или оборванный файл и файл GeoIP, загруженный как GeoSite, отклоняются, а текущий файл остаётся на месте. Новая копия пишется рядом с текущей, поэтому для обновления нужно место под обе. Файлы занимают примерно от 10 МБ до более чем 70 МБ. Если прямая закачка источника из списка не удалась, b4 повторяет её через зеркала обновлений.

Если файл всё же повреждён, например из-за заполненного диска, теряются только категории, которые b4 не может прочитать. Сеты продолжают совпадать по остальным целям, а лог называет затронутые категории и сеты. Отсутствующий или повреждённый файл скачивается заново по URL источника независимо от полей Автообновление.

Автообновление​

ПолеЧто делаетПо умолчанию
Обновлять при запускеВскоре после старта b4 скачивает каждую базу, у которой есть URL источникаВыключено
РасписаниеЕжедневно, Еженедельно или Ежемесячно: скачивает каждую базу с URL источника, когда с последнего запуска прошло 24 часа, 7 или 30 днейВыключено
Последний запускКогда фоновая закачка последний раз обновила все базы с URL источника. Обновить его не меняет-

Оба поля сохраняются кнопкой Сохранить и действуют без перезапуска. Фоновые закачки работают, только пока включён веб-сервер: при порте 0 ничего не скачивается, в том числе отсутствующие файлы.

Категории в сетах​

Когда у базы есть путь, редактор сета показывает её категории на вкладке Цели: Категории GeoSite обхода на подвкладке Домены обхода и Категории GeoIP обхода на подвкладке IP обхода. У каждой выбранной категории видно число доменов или диапазонов адресов, а нажатие на категорию GeoSite открывает просмотр её первых 100 доменов. Как сеты совпадают по категориям, описано на странице Цели.
