b4 только для выбранных устройств

По умолчанию b4 обрабатывает трафик всех устройств в сети. Фильтрация устройств в разделе Настройки > Основные > Устройства определяет, какие устройства вообще получают обход DPI. Исходные устройства сета ограничивают некоторыми устройствами только этот сет.

Требования​

  • Устройства находятся в сети роутера, где b4 находит их в таблице ARP.
  • У устройства за другим роутером фиксированный или зарезервированный IP-адрес: добавить его можно только по этому адресу.

Выбор устройств, которые получают обход DPI​

  1. Откройте Настройки > Основные > Устройства.
  2. Включите Включить фильтрацию устройств.
  3. В списке Доступные устройства выберите устройства. Устройство, которого нет в списке, добавьте в разделе Ручные устройства по IP-адресу.
  4. Чтобы исключить выбранные устройства из обхода, а не ограничить обход ими, включите Исключить выбранные устройства (чёрный список).
  5. Нажмите Сохранить, затем Перезапустить сервис. Выбор применяется после перезапуска.

Что охватывает фильтр:

  • Обход DPI сопоставляет устройства по MAC-адресу. Устройство, добавленное вручную, для него не учитывается, а если выбраны только такие устройства, обход DPI действует для всех устройств.
  • Сеты маршрутизации и Telegram через WebSocket применяют тот же выбор к трафику из сети. Там устройство, добавленное вручную, сопоставляется по IP-адресу.
  • Сам роутер не считается устройством. Его собственные соединения, в том числе соединения SOCKS5-прокси, получают обход DPI в обоих режимах.
  • Пока выбраны устройства, сеты не записывают собственное значение DSCP.

Поля описаны в разделе Устройства.

Сет только для некоторых устройств​

  1. Откройте сет, затем Цели > Исходные устройства.
  2. Выберите устройства.
  3. Чтобы сет действовал для всех устройств, кроме выбранных, включите Все устройства, кроме выбранных.
  4. Сохраните сет.

Сет, ограниченный исходными устройствами, имеет приоритет над сетом без такого ограничения. Исходные устройства сужают круг тех, к кому применяется сет, но сами трафик не выбирают. Сету маршрутизации по-прежнему нужна цель: домен, IP или ASN, а Любой IP-адрес на вкладке IP обхода уводит весь трафик этих устройств. См. Исходные устройства.

Проверка результата​

  1. Откройте Трафик.
  2. На панели Устройства выберите устройство.
  3. У его соединений указан сет, с которым каждое из них совпало.

Устройства, исключённые фильтрацией, не получают обхода DPI, а дашборд не учитывает их соединения.

Если не работает​

  • После сохранения ничего не изменилось. Фильтрация устройств применяется после перезапуска b4.
  • Устройство, добавленное вручную, не получает обхода DPI. Обход DPI сопоставляет устройства только по MAC-адресам. Такое устройство всё же может быть исходным устройством сета.
  • Устройство, добавленное вручную, не сопоставляется. Его IP-адрес изменился, или промежуточный роутер подменяет адрес источника его трафика. В первом случае нужен фиксированный или зарезервированный адрес, во втором сопоставить устройство нельзя.
  • Телефон перестал сопоставляться. Многие телефоны используют случайный MAC-адрес, он отображается как Private, и новый адрес для b4 - новое устройство. Если на телефоне отключить частный адрес для этой сети, MAC-адрес останется постоянным.
  • Устройство, которого больше нет, остаётся в списке с отметкой «не в сети». b4 хранит имя, выбор и значение MSS устройства, пока его не забудут в списке Доступные устройства. Новое устройство на замену или телефон с новым случайным MAC-адресом для b4 - новое устройство, и его выбирают заново.
