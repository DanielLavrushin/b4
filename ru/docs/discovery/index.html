Дискавери

Дискавери ищет стратегию обхода для сайтов из поля ввода или для страниц одного сета. Результат становится новым сетом или записывается в существующий. Настроенные сеты во время поиска продолжают работать.

Первый запуск разобран в руководстве Обход блокировки сайта, а в Поддержании работы сетов показано, как мониторинг запускает Дискавери сам. Подробно о запуске - на странице Как Дискавери ищет стратегию.

Ввод​

Сайт или URL принимает домены или полные URL через запятую или с новой строки. Домен запрашивается как https://<домен>/, URL - как указан. Локальные и частные адреса отклоняются.

Поиск стратегии для сета запускает Дискавери для одного сета и заполняет поле его адресами Дискавери или предложениями. Запуск для сета проверяет не больше пяти адресов. Сет, который направляет трафик в прокси или интерфейс, выбрать нельзя. Если адрес из поля обрабатывает другой сет, предупреждение называет этот сет. Пункт Найти стратегию в меню карточки сета или на вкладке Дискавери редактора открывает эту страницу с уже выбранным сетом.

Параметры​

Обычно значения по умолчанию менять не нужно.

Запуск​

Начать запускает поиск из шести шагов: DNS, Без обхода, Стратегии, Подбор параметров, Комбинации и Подтверждение. Строка на сайт показывает, что найдено к этому моменту, а Показать журнал открывает журнал. Запуск занимает от одной до десяти минут в зависимости от сети.

Остановить и подтвердить завершает поиск и подтверждает найденное, без подбора параметров. Остановить завершает запуск, который ещё ничего не нашёл. Остановить сейчас во время подтверждения завершает запуск сразу, а результаты остаются неподтверждёнными.

Запуск останавливается, если во время поиска b4 переписывает свои правила DSCP, например после сохранения нового значения DSCP сета. Его результаты применить нельзя, а история помечает строку остановлено: правила файрвола изменились во время поиска, нужен повторный запуск.

Одновременно идёт только один запуск, включая поиски мониторинга. Поиск мониторинга виден на этой странице, но остановить его отсюда нельзя.

Запуск для сета​

Запуск для сета заканчивается одним вердиктом на весь сет, который показан над блоком Результаты по адресам. Первой проверяется собственная стратегия сета, Текущая стратегия сета, а найденная стратегия подтверждается на всех адресах вместе.

Для сета с собственным значением DSCP проверочные запросы несут это значение, как и трафик сета, и идут маршрутом сета через роутер перед b4. Ход поиска и результаты показывают DSCP <значение>, как у трафика сета. Запросы любого другого запуска несут значение Задать DSCP из Настройки > Основные > Файрвол, пока оно включено, или никакого, в том числе к адресам такого сета.

ВердиктЗначение и что предлагает карточка

Она также напоминает, что браузер может использовать QUIC (HTTP/3), который Дискавери не проверяет, или другую версию IP, чем запуск, например IPv6. Версия IP для проверок задаёт версию, которую проверяет запуск.

Результаты​

Каждый сайт получает карточку, а в запуске для сета карточки собраны в блоке Результаты по адресам.

БейджЗначение и что делать
подтверждена 3 из 3, не подтвержденаСайт открыла стратегия, исправление DNS, альтернативный адрес или удаление ключа ECH. Карточка описывает сет, который будет создан.
обход не нуженСайт открывается без b4.
адрес заблокированСоединения со всеми известными адресами не проходят, и стратегия обхода не поможет. Сайту нужен VPN или прокси.
перехвачен шлюзомНа соединение отвечает сам первый узел перед этим хостом. b4 должен работать на этом шлюзе, либо этот хост нужно исключить из его перенаправления. Если b4 и есть роутер, поможет только прокси.
имя не резолвитсяУ имени нет адреса, как бывает при опечатке в домене.
ссылка отвечает 400Ссылка получает HTTP 400 даже без b4. Нужна ссылка на страницу или файл, которые отдаёт сайт.
ничего не найденоНи одна стратегия не сработала. Иногда помогает новый запуск с TLS 1.2 или с захваченным ClientHello.

Сайты с одной и той же стратегией-победителем делят одну карточку и один сет. Сработали ещё N стратегий перечисляет остальные стратегии, открывшие сайт, быстрые первыми, у каждой есть Взять вместо неё. Победитель - самый быстрый по одному запросу, а это шумная мера: стратегия из списка - столь же законный выбор.

Применение​

Применить как сет, Применить в истории и Взять вместо неё открывают один и тот же диалог. Он показывает будущий сет и предлагает:

  • Создать новый сет, затем Создать сет: см. Создание сета.
  • Записать стратегию в существующий сет, затем Заменить стратегию: см. ниже. Этот вариант выбран по умолчанию, если запуск шёл для сета или какой-то сет указывает сайт точно.
  • Добавить в <имя>, где уже используется та же стратегия, затем Добавить в сет: сайты добавляются в этот сет. Если стратегия сета изменилась после открытия диалога, ничего не добавляется.

Копировать JSON копирует сет, не создавая его, в формате вкладки Импорт/Экспорт.

Результат применяется только к сету, трафик которого идёт тем сетевым путём, который проверял запуск: со значением DSCP проверочных запросов, записанным на тех же интерфейсах. Изменение значения DSCP сета, Задать DSCP или его списка интерфейсов после запуска может изменить этот путь. Тогда ошибка называет разницу, а новый запуск для сета проверяет новый путь. Несколько секунд после сохранения такого изменения, пока b4 применяет правила DSCP, применение и запуск поиска отклоняются.

Запись в существующий сет​

Какой сет изменить перечисляет сет запуска и включённые сеты без маршрутизации, которые уже совпадают с сайтом. Другой сет позволяет выбрать любой другой сет без маршрутизации. Записывается только стратегия обхода: TCP, фрагментация, фейки, а если результат их использует, DNS-перенаправление, закреплённые адреса и удаление ключей ECH. Фильтр портов, защита от RST, UDP, цели, маршрутизация и эскалация остаются как были. Сохранить эти адреса как адреса Дискавери для сета заодно заменяет адреса Дискавери сета.

Если сет не совпадает с сайтами, Добавить <сайты> в этот сет добавляет их и убирает из других включённых сетов. Диалог предупреждает, когда сайт на деле обрабатывает другой сет: там новая стратегия не действует.

Создание сета​

Предлагаемое Название сета - сайт без префикса и домена верхнего уровня. Совпадение позволяет сократить один сайт до родительского домена, чтобы сет покрывал и поддомены. Сайт, указанный в другом включённом сете, переносится в новый.

Новый сет появляется в начале списка и сразу включён. DNS-перенаправление или закреплённые адреса он получает только для сайта, которому они понадобились. Проверенные адреса становятся его адресами Дискавери, поэтому сет можно снова проверить или поставить на мониторинг.

Альтернативные адреса​

Часть блокировок выдаёт адрес, который не принимает ни одного соединения, хотя клиенты в других регионах получают рабочие адреса. При включённом Проверять подмену DNS Дискавери ищет такие адреса, когда все известные адреса сайта недоступны. Сет закрепляет имя сайта за адресами, прошедшими TLS-рукопожатие, не больше трёх, и устройства получают их в ответах DNS.

Закреплённые адреса фиксируются на момент запуска. Если блокировка переезжает, новые находит новый запуск с проверкой DNS. Поиски мониторинга проверку DNS пропускают и закрепления не обновляют.

Сайты с ключом ECH​

Сайт, который публикует ключ ECH, проверяется так, как подключается браузер с этим ключом, поэтому ClientHello называет публичное имя из ключа, например cloudflare-ech.com. Сет нацелен и на это имя.

Если сеть отбрасывает ClientHello с ECH, а без ECH сайт открывается, карточка помечена ECH блокируется, а результат - Ключи ECH убраны. Такой сет включает Убирать ключи ECH из ответов DNS и пакеты не меняет. Браузер со своим защищённым DNS всё равно отправляет ECH, и ему нужна одна из других стратегий под результатом.

История​

История хранит последний результат по каждому сайту, новые сверху.

  • Применить создаёт сет, собранный запуском, без нового запуска.
  • Повторить запускает поиск заново для сайта или для сета, из которого пришла строка.
  • Удалить из истории и Очистить историю удаляют одну строку или все.
  • Строка раскрывается в список других сработавших стратегий, у каждой есть Взять вместо неё.
  • Пробовали отмечает стратегию, которую уже применяли как сет, даже если сет удалён.
  • через мониторинг и через MCP отмечают запуски, начатые мониторингом или ИИ-ассистентом через MCP.

Журнал последнего запуска открывает журнал последнего запуска, в том числе после перезапуска, и позволяет скачать его текстовым файлом.
